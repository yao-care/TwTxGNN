# Hydroxyprogesterone caproate：從習慣性流產到子宮內膜異位症

## 一句話總結

Hydroxyprogesterone caproate 是一種合成黃體素（孕激素），在台灣原本用於習慣性流產、先兆流產與機能性子宮出血等婦科病症。
TxGNN 模型預測它可能對**子宮內膜異位症 (Endometriosis of uterus)** 有效，但目前**沒有臨床試驗**，只有 **1 篇文獻**（個案報告，且未實際測試此藥）支持這個方向，證據偏弱。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Hydroxyprogesterone caproate 是一種合成黃體素，能對抗雌激素驅動的子宮內膜增生。

子宮內膜異位症是異位的內膜組織受雌激素刺激而生長，黃體素類藥物在理論上可抑制這類組織。原適應症（機能性子宮出血、痛經、習慣性流產）也都與子宮內膜與黃體素不足有關，兩者在病理生理上有相近之處。

不過，目前取得的唯一文獻是一例妊娠期自發性腹腔出血的個案報告，內容並未測試此藥，因此這個預測目前主要來自機轉上的合理推論，缺乏直接證據。

## 結論與下一步

**決策：Hold**

**理由：**
TxGNN 分數很高，機轉上也合理，但沒有任何臨床試驗，唯一文獻也未實際評估此藥用於子宮內膜異位症，證據僅達前臨床／機轉層級（L4）。另外，同一批預測中，子宮體癌與子宮內膜癌雖有較多早期文獻（L3），但多為 1970–1990 年代的小型病例研究與世代研究，且缺乏隨機試驗。

**若要推進需要：**
- 取得 Hydroxyprogesterone caproate 的作用機轉資料（MOA）
- 系統性搜尋此藥用於子宮內膜異位症的臨床與前臨床研究
- 與現行標準治療（其他黃體素類、GnRH 類藥物等）比較的證據
- 評估注射劑型對慢性治療的可行性與耐受性
- 針對上述潛在禁忌族群（如高血壓、糖尿病、肝病、乳癌病史）訂定篩選與監測計畫
