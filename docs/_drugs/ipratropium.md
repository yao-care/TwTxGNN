## Ipratropium：抗膽鹼支氣管擴張劑 → 鼻腔疾病 (nasal cavity disease)
{: .text-alpha }

## 一句話總結

Ipratropium（溴化伊普托品）是一種抗膽鹼（毒蕈鹼受體拮抗）藥物，主要以吸入或鼻用劑型使用。
TxGNN 模型預測它可能對**鼻腔疾病 (nasal cavity disease)** 有效，
目前**無臨床試驗**，僅有 **2 篇間接文獻**（一篇帕金森氏症鼻內給藥回顧、一篇過敏性鼻炎的動物實驗）。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ipratropium 為毒蕈鹼受體拮抗劑，可阻斷膽鹼性神經對腺體與平滑肌的刺激。

在鼻腔，鼻黏膜下腺體受膽鹼性神經調控，阻斷毒蕈鹼受體理論上可減少分泌物，緩解流鼻水。這是預測在機轉上的合理之處。

但目前取得的文獻只有間接證據：一篇是帕金森氏症鼻內給藥的回顧，與鼻腔疾病無直接關聯；另一篇是過敏性鼻炎的水凝膠遞送動物研究，屬前臨床。沒有任何研究在人體直接評估 ipratropium 對「鼻腔疾病」這個預測疾病的效果，因此證據等級定為 L5。

## 安全性考量

- **藥物交互作用**：共 106 筆交互作用紀錄，主要為中度等級，多與其他抗膽鹼藥物併用有關，例如 Atropine、Hyoscyamine、Glycopyrronium、Scopolamine、Dicyclomine，另有 Promethazine、Chlorpheniramine 等。併用可能加重抗膽鹼作用。
- **需留意的相關疾病**：資料顯示下列疾病族群需特別評估，包括閉角型青光眼、良性攝護腺增生、膀胱頸阻塞、長 QT 症候群、心肌缺血與冠狀動脈疾病、甲狀腺機能亢進、癲癇、糖尿病酮酸中毒及高血壓。這些並非仿單禁忌，僅供風險評估參考。
- **過敏風險**：有 ipratropium 吸入後發生嚴重過敏反應的個案報告。

其餘安全性資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何研究直接評估 ipratropium 對鼻腔疾病的效果，目前僅有間接文獻與模型預測，證據等級為 L5。
- 缺乏作用機轉資料，且預測疾病範圍過於籠統，不利於設計驗證。

**若要推進需要：**
- 補充詳細的作用機轉資料。
- 將「鼻腔疾病」具體化為明確的臨床適應症（如過敏性或非過敏性鼻炎的流鼻水），並檢視現有鼻用抗膽鹼劑的臨床證據。
- 若要進一步評估，需規劃含鼻黏膜耐受性與抗膽鹼副作用監測的臨床試驗設計。
