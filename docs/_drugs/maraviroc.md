# Maraviroc：從 HIV-1 感染到多發性內分泌腫瘤

## 一句話總結

Maraviroc 是 CCR5 拮抗劑，原本用於治療僅具 CCR5 趨性之 HIV-1 感染成人患者。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia)** 有效，
但目前**沒有任何臨床試驗與文獻**直接支持此方向，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Maraviroc 是 CCR5 拮抗劑，透過阻斷 HIV-1 進入細胞所需的 CCR5 共受體發揮抗病毒作用。

然而，目前沒有臨床或文獻證據將 CCR5 阻斷與多發性內分泌腫瘤連結起來。原適應症（病毒感染）與預測適應症（遺傳性內分泌腫瘤症候群）在疾病性質上差異很大，兩者之間的關聯目前僅來自 TxGNN 的預測。

因此，這個預測應視為待驗證的假設，而非已有支持的方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.82%），但沒有任何臨床試驗或文獻支持，證據等級僅為 L5。
- 缺乏作用機轉資料，且 CCR5 阻斷與多發性內分泌腫瘤之間沒有已知的生物學連結。

**若要推進需要：**
- 補充 Maraviroc 的作用機轉資料，並建立 CCR5 與多發性內分泌腫瘤的機轉假設
- 進行前臨床研究（細胞或動物模型）驗證 CCR5 阻斷的效果
- 系統性檢索文獻與臨床試驗登記，確認是否有未被收錄的相關研究
- 若有進展，評估肝、腎、心血管風險族群及藥物交互作用（特別是 CYP3A 抑制劑如 Clarithromycin）的安全性監測計畫
- 同時可考慮優先評估證據相對較具機轉合理性的候選適應症（如 HER2 陽性乳癌、皮膚 T 細胞淋巴瘤）
