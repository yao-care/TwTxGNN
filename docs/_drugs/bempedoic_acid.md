## Bempedoic acid：ATP 檸檬酸裂解酶抑制劑 → 甲狀腺機能亢進 (hyperthyroidism)
{: .text-alpha }

## 一句話總結

Bempedoic acid 是一種口服降膽固醇藥物，作用於肝臟膽固醇合成路徑。
TxGNN 模型預測它可能對**甲狀腺機能亢進 (hyperthyroidism)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料庫記載。根據已知資訊，bempedoic acid 透過抑制 ATP 檸檬酸裂解酶（ATP-citrate lyase）來減少肝臟的膽固醇合成。

就現有資料而言，這個機轉與甲狀腺機能亢進之間**沒有已建立的直接關聯**。甲狀腺激素訊號雖會影響肝臟脂質代謝，但 bempedoic acid 並不作用於甲狀腺激素受體或甲狀腺功能路徑。

因此，這項預測目前只能視為模型推論，缺乏臨床或文獻佐證，不能視為有根據的治療訊號。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測疾病沒有任何臨床試驗或文獻支持，作用機轉與甲狀腺機能亢進亦無已知關聯，證據等級為 L5。
- 單憑模型分數不足以支持推進。

**若要推進需要：**
- 建立 ATP 檸檬酸裂解酶抑制與甲狀腺功能之間的機轉假說，並以前臨床研究驗證
- 取得完整的作用機轉資料
- 搜尋或設計針對甲狀腺機能亢進的探索性研究
- 評估與皮質類固醇、statin 類藥物併用時的交互作用風險
