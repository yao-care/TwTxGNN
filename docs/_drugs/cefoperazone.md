# Cefoperazone：從抗生素（細菌感染）到硬化性膽管炎

## 一句話總結

Cefoperazone（頭孢哌酮）是一種頭孢菌素類抗生素，原本用於治療感受性細菌引起的感染。
TxGNN 模型預測它可能對**硬化性膽管炎 (Sclerosing Cholangitis)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，Cefoperazone 是 β-內醯胺類抗生素，透過結合細菌的青黴素結合蛋白 (PBP) 來抑制細胞壁合成。它在膽汁中的排泄濃度很高，這是它與膽道疾病之間最直接的連結。

因此，這個預測在機轉上只有一種合理的情況：**硬化性膽管炎併發細菌性膽管炎**。這種情況下，抗生素可以治療感染。

但硬化性膽管炎本身的核心病程是自體免疫與纖維化，Cefoperazone 對這個過程沒有已知作用。因此，它不太可能改變疾病本身的進程，只能處理合併的細菌感染。這也與原適應症中已列有膽囊炎、膽管炎等感染重疊，不算真正的新適應症。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**（來自模型知識圖譜的藥物－疾病關聯，不是仿單內容）：肝病、膽囊疾病、血液凝固疾病、困難梭狀桿菌結腸炎、新生兒壞死性腸炎、先天性凝血酶原缺乏、維生素 K 缺乏出血症、消化系統疾病、腸道疾病。其中肝病與膽囊疾病與預測的新適應症直接相關，使用前需特別評估。
- **藥物交互作用**：共 14 項，皆為中度。主要包括：
  - 胺基糖苷類抗生素：Kanamycin、Neomycin、Streptomycin、Amikacin、Gentamicin
  - 抗凝血藥：Warfarin、Heparin
  - 其他：Ethanol、Chloramphenicol、Ethinylestradiol、Mycophenolic acid、Pemetrexed、Picosulfuric acid

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只有模型分數支持，沒有臨床試驗或文獻佐證（L5）。
- 藥物的作用方式是抗菌，對硬化性膽管炎的自體免疫與纖維化病程沒有已知作用。唯一合理的用途是治療合併的細菌性膽管炎，而這已涵蓋在既有的感染適應症內。

**若要推進需要：**
- 釐清目標是「治療疾病本身」還是「治療合併的細菌性膽管炎」。若為後者，應視為既有適應症的延伸使用，而非新適應症。
- 搜尋並蒐集 Cefoperazone 用於硬化性膽管炎病人的臨床或觀察性資料。
- 補齊詳細的作用機轉資料。
- 評估肝膽疾病病人使用時的安全性，包括凝血功能與肝功能監測，以及已知交互作用藥物的管理。
