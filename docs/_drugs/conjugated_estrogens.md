# Conjugated estrogens：從更年期相關症狀與卵巢機能不全到偏頭痛

## 一句話總結

Conjugated estrogens（共軛雌激素）是一種女性荷爾蒙製劑，原本用於更年期障礙、卵巢機能不全、萎縮性陰道炎與機能性子宮出血等。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，
目前**無臨床試驗登記**，僅有 **5 篇文獻**（以回顧與世代研究為主）支持這個方向，且研究結果好壞參半。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，共軛雌激素是天然來源的混合雌激素，可補充體內不足的雌激素，用於更年期與卵巢機能不全相關症狀。

偏頭痛，特別是月經期與停經過渡期的偏頭痛，與雌二醇濃度下降或劇烈波動有關。因此理論上，穩定的雌激素補充可能減少部分女性的發作。

不過，現有觀察性資料顯示結果不一致：有些女性接受荷爾蒙治療後症狀改善，有些反而惡化。此外，雌激素有血栓與中風風險，在有預兆的偏頭痛族群中尤其需要留意。

## 安全性考量

- **藥物交互作用**：共有 109 筆交互作用紀錄，以下為部分例子：
  - 中度：Acarbose、Alogliptin、Canagliflozin、Dapagliflozin、Empagliflozin 等降血糖藥物
  - 中度：Hydrocortisone、Dexamethasone、Betamethasone、Budesonide、Triamcinolone 等皮質類固醇
  - 中度：Aprepitant、Clarithromycin、Clotrimazole
  - 輕度：Cimetidine
- **與預測適應症相關的風險**：雌激素會增加血栓與中風風險，在有預兆的偏頭痛患者中尤其需要審慎評估。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前僅有回顧與觀察性研究，且結果不一致，沒有臨床試驗或隨機對照試驗證據；雌激素的血栓與中風風險，在偏頭痛（特別是有預兆者）族群中更需謹慎，因此現階段不建議推進。

**若要推進需要：**
- 取得共軛雌激素詳細的作用機轉資料（MOA）
- 針對偏頭痛設計前瞻性或隨機對照試驗，並依有無預兆分層
- 建立血栓與中風風險的篩選與排除標準
- 評估給藥途徑與劑量（口服與經皮的差異）對偏頭痛的影響
- 確認台灣現行有效許可證的適應症範圍，並評估是否需要申請新增適應症
