# Pimozide：從精神病狀態到拔毛症（Trichotillomania）

## 一句話總結

Pimozide（匹莫靜）是一種二苯基丁基哌啶類抗精神病藥，在台灣核准用於精神病狀態。
TxGNN 模型預測它可能對**拔毛症 (Trichotillomania)** 有效，
目前**無臨床試驗登記**，但有 **9 篇文獻**（以回顧與病例系列為主）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Pimozide 是強效的多巴胺 D2 受體拮抗劑，用於精神病狀態的療效已被證實。

拔毛症屬於重複性行為障礙，與妥瑞氏症、強迫症在臨床表現與治療反應上有部分重疊。多巴胺系統在習慣形成與重複行為迴路中的失調，是一個合理的作用標的。

文獻中也有實際使用紀錄：Stein 與 Hollander（1992）報告以低劑量 pimozide 加強血清素再吸收抑制劑（SRI）治療拔毛症，Epperson 等人（1999）的文章亦提到，開放標示加入低劑量 pimozide 對部分 SRI 難治型拔毛症患者有益。不過這些都是小型、非對照的研究，尚不足以確認療效。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自藥物與疾病關聯資料，非仿單內容）：長 QT 症候群（含家族性）、尖端扭轉型心室頻脈、心臟傳導疾病、心因性猝死、癲癇、青光眼、良性攝護腺增生、肝病、腎病、低鉀血症、嗜中性球低下症／顆粒球缺乏症／白血球低下、抗精神病藥惡性症候群、阿茲海默症等。其中心律相關風險（QT 延長）是此藥需要特別留意的重點。
- **藥物交互作用**：資料庫共記錄 247 筆。列為重大（Major）者包括 hydrocortisone、amphotericin B、bupropion、aprepitant、morphine、lorcaserin、cimetidine、clarithromycin、potassium citrate 等；中度（Moderate）者包括 famotidine、epinephrine、atropine、loperamide 等。使用前應完整審視併用藥物。

主要警語與仿單禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，證據僅限於回顧文章與少數小型病例系列（L4），且缺乏 MOA 資料。
- Pimozide 有 QT 延長與多項禁忌疾病等安全性顧慮，而拔毛症有其他風險較低的治療選項，風險效益比尚待釐清。

**若要推進需要：**
- 補齊 Pimozide 的作用機轉資料，以及仿單的警語與禁忌症
- 設計小型前瞻性對照試驗（例如 SRI 難治型拔毛症的加強療法），並與其他抗精神病藥（如 risperidone）比較
- 建立心電圖（QT）與藥物交互作用的監測與篩選機制
- 確認台灣有效許可證（目前僅少數仍有效）的實際供貨狀況
