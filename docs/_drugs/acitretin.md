# Acitretin：從嚴重性牛皮癬到痤瘡

## 一句話總結

Acitretin 是口服第二代類視色素（retinoid），原本用於嚴重性牛皮癬與皮膚角化症。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，但目前僅有 **1 個相關的臨床試驗**（針對化膿性汗腺炎，而非尋常性痤瘡）和**數篇間接文獻**，證據屬間接、早期階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Acitretin 屬於口服類視色素，一般認為它透過 RAR/RXR 核受體，調節毛囊角質細胞的分化，並減少角化過度與發炎。

痤瘡與牛皮癬、角化症都和角質細胞分化異常及發炎有關，因此機轉上有可能適用。同類藥物 isotretinoin 已是重度痤瘡的標準類視色素，這也支持此預測的方向。

不過，Acitretin 用於痤瘡的直接證據有限。現有資料主要來自化膿性汗腺炎（又稱 acne inversa，是另一種毛囊阻塞性疾病）的研究與個案報告，並非尋常性痤瘡。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜，非仿單文字）：肝衰竭、藥物性肝損傷、胰臟炎、高三酸甘油脂血症、糖尿病與酮酸中毒、肥胖、顱內高壓／假性腦瘤、視覺障礙／夜盲、骨質增生（hyperostosis）、焦慮及情緒相關疾患、物質濫用／依賴等。
- **藥物交互作用**：共 113 筆，主要包括：
  - **Major**：Doxycycline、Minocycline、Tetracycline（四環黴素類）、Vitamin A
  - **Moderate**：多種磺醯脲類降血糖藥（Acetohexamide、Chlorpropamide、Glimepiride、Glipizide、Glyburide、Tolazamide、Tolbutamide）、Naltrexone
- 另依現有資料，Acitretin 為已知致畸胎藥物，懷孕期間不可使用。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 痤瘡的證據只有間接來源：一個針對化膿性汗腺炎的 Phase 4 試驗、少量個案報告及綜述，沒有針對尋常性痤瘡的試驗。
- 痤瘡已有 isotretinoin 等標準類視色素，而 acitretin 的致畸胎性與其他安全性風險顯著，需要更強的證據才能支持推進。

**若要推進需要：**
- 取得 NCT07708480 的結果，並評估化膿性汗腺炎的證據能否外推到痤瘡。
- 補充詳細的作用機轉資料（MOA）。
- 設計針對痤瘡、與 isotretinoin 比較的臨床研究。
- 規劃嚴格的避孕與懷孕預防方案，並監測肝功能與血脂。
