# Timepidium：從胃炎與平滑肌痙攣性疼痛到失眠

## 一句話總結

Timepidium（梯每匹定）是一種抗痙攣、鎮痛藥物，原本用於緩解胃炎、消化性潰瘍、腸炎、膽道疾患、尿路結石及胰臟炎所伴隨的平滑肌痙攣性疼痛。
TxGNN 模型預測它可能對**失眠 (Insomnia)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，屬於純模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Timepidium 屬於四級銨類抗蕈毒鹼（antimuscarinic）抗痙攣藥，其在消化道與泌尿道平滑肌痙攣引起之疼痛中的用途已被臨床採用。

然而，從藥理角度看，這個預測的機轉支持度偏低。四級銨結構使藥物難以穿過血腦屏障，因此不預期會有直接的中樞性助眠作用。TxGNN 給出高分，較可能反映知識圖譜中的間接關聯（例如與其他抗膽鹼類藥物的網絡相似性），而不是已被驗證的生物學機轉。

也就是說，模型分數雖高（99.45%），但目前沒有任何實證可以說明 Timepidium 能改善失眠。若有任何間接效益（例如因疼痛緩解而改善睡眠），也屬於推測，需要另行驗證。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有臨床試驗或文獻佐證。
- 四級銨結構難以進入中樞神經，機轉上不支持直接的助眠作用，且作用機轉資料缺漏。

**若要推進需要：**
- 補齊作用機轉資料（MOA），並釐清模型高分背後的圖譜關聯路徑。
- 進行文獻與臨床試驗登記的系統性檢索，確認是否有任何失眠相關的研究訊號。
- 若仍要探索，先以前臨床或機轉研究評估中樞作用（含血腦屏障穿透性）的可能性。
- 補充安全性資料（警語、禁忌、藥物交互作用），特別是抗膽鹼作用在失眠族群（如高齡者）的風險。
