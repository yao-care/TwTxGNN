# Methionine：從肝機能障礙到痤瘡

## 一句話總結

Methionine 原本用於治療肝機能障礙及藥物中毒。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，
目前有 **4 篇文獻**支持這個方向，但缺乏臨床試驗證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Methionine 是一種氨基酸，
在肝機能障礙中的療效已被證實，機轉上可能通過影響同型半胱氨酸代謝間接影響皮膚健康，
但缺乏直接證據支持其對痤瘡的療效。
