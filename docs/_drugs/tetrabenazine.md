# Tetrabenazine 藥師筆記

## 一句話總結

## 為什麼這個預測合理

### 作用機轉支持

Tetrabenazine 透過可逆性抑制囊泡單胺轉運蛋白 2（VMAT2），減少多巴胺、血清素和正腎上腺素在神經末梢的儲存和釋放，從而減少過度運動症狀。

### 預測適應症分析

1. **多囊性腎病第 3 型（PKD3）**
   - TxGNN 分數：0.756
   - 機轉關聯：間接，可能與 cAMP 信號通路有關
   - 證據等級：僅有知識圖譜預測

2. **腎-肝-胰發育不全**
   - TxGNN 分數：0.712
   - 機轉關聯不明確
   - 證據等級：僅預測

3. **乳乙伯症候群（Joubert syndrome）**
   - TxGNN 分數：0.698
   - 機轉關聯不明確
   - 證據等級：僅預測

### 機轉分析的挑戰

TxGNN 的預測主要基於知識圖譜中的關聯性，而非直接的機轉證據。Tetrabenazine 作為 VMAT2 抑制劑，其在腎臟疾病中的潛在作用機轉不明確：

- 可能的假說：單胺類神經傳導物質對腎臟囊腫生長有影響
- 目前無直接證據支持

### 主要不良反應

- **常見**：嗜睡、疲勞、帕金森症狀、噁心
- **較少見**：憂鬱、焦慮、失眠、靜坐不能
- **嚴重**：
  - **憂鬱與自殺風險**（黑框警告）
  - 惡性神經抑制症候群（NMS）
  - QT 延長

### 黑框警告

**憂鬱與自殺風險**：
- Tetrabenazine 可能導致或惡化憂鬱症
- 患者可能出現自殺意念
- 需密切監測情緒變化
- 有重度憂鬱症病史者禁用

### 特殊族群注意事項

- **肝功能不全**：需減量
- **CYP2D6 代謝差者**：需減量
- **老年人**：謹慎使用，副作用風險增加
- **懷孕**：Category C
