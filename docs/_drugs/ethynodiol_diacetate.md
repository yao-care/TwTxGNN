# Ethynodiol diacetate：從避孕與抑制排卵到痤瘡

## 一句話總結

Ethynodiol diacetate 是一種黃體素（progestin），在台灣以複方口服避孕藥的成分上市，原本用於避孕、抑制排卵與月經異常。
TxGNN 模型預測它可能對**痤瘡 (Acne)** 有效，
目前**沒有臨床試驗登記**，僅有 **10 篇文獻**（多為早期觀察性研究與綜述）支持這個方向。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Ethynodiol diacetate 是複方口服避孕藥的一部分，其成分在避孕與抑制排卵上的作用已被證實。

在複方避孕藥中，Ethynodiol diacetate 常與 ethinyl estradiol 合用。雌激素成分可抑制卵巢雄性素的產生，並提高性荷爾蒙結合球蛋白（SHBG），因而可能減少皮脂分泌並改善痤瘡。

需要注意的是，這類黃體素本身仍帶有一些殘餘的雄性素活性，可能部分抵銷上述效果。因此，痤瘡改善主要應歸功於複方中的雌激素成分，Ethynodiol diacetate 本身的貢獻並不明確。

## 安全性考量

TxGNN 知識圖譜中，有下列疾病與本藥存在禁忌關聯（此為圖譜資料，並非仿單原文）：

- **心血管與代謝**：高血壓、冠狀動脈疾病、中風與腦血管疾病、血栓性靜脈炎、高血糖、糖尿病、糖尿病酮酸中毒、高三酸甘油脂血症、高脂血症、肥胖
- **肝膽**：肝臟疾病、膽囊疾病、紫質症
- **荷爾蒙相關腫瘤**：女性乳癌、子宮內膜癌
- **神經與精神**：偏頭痛、焦慮症、神經症、輕鬱症

此外，文獻中有口服避孕藥與視網膜血管損傷等眼部不良反應的報告，可能與雌激素相關的血栓效應有關。

其餘警語、禁忌症與藥物交互作用，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有任何臨床試驗，文獻多為舊的觀察性研究與綜述，且痤瘡改善主要來自複方中的雌激素成分，Ethynodiol diacetate 本身的貢獻不明確。
- 該藥具有殘餘雄性素活性，且禁忌症廣泛（心血管、血栓、荷爾蒙相關腫瘤等），相較於已有明確證據的痤瘡療法，效益與風險比尚待釐清。

**若要推進需要：**
- 補充詳細的作用機轉資料（MOA）
- 設計比較含與不含 ethynodiol diacetate 複方的對照研究，釐清該成分對痤瘡的獨立貢獻
- 與現有含抗雄性素黃體素的避孕藥進行療效與安全性比較
- 針對有高風險族群（心血管、血栓、偏頭痛等）建立篩選與排除標準

**其他預測適應症備註：** 女性不孕症（L4）的機轉與本藥抑制排卵作用相反，建議 Hold；46,XY 性發育異常、縱向及橫向陰道中隔皆無任何臨床或文獻證據（L5），且陰道中隔為結構性異常，激素治療無法矯正；眼部疾病的文獻顯示的是安全疑慮而非治療效益。
