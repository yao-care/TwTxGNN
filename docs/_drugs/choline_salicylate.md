## Choline salicylate：水楊酸類消炎止痛成分 → 變異型心絞痛 (Prinzmetal angina)
{: .text-alpha }

## 一句話總結

Choline salicylate 是一種非乙醯化的水楊酸類藥物，具有解熱、消炎與止痛作用。
TxGNN 模型預測它可能對**變異型心絞痛 (Prinzmetal angina)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，水楊酸類藥物可抑制環氧合酶 (COX) 與血小板血栓素 A2 的生成，理論上可能影響血管痙攣相關的路徑。

然而，變異型心絞痛的核心病理是冠狀動脈痙攣，而水楊酸類（尤其是高劑量阿斯匹靈）反而可能加重血管痙攣。Choline salicylate 本身也沒有明確的血管擴張作用，因此機轉上的支持相當薄弱。

整體而言，這項預測目前僅來自模型分數，缺乏機轉與臨床證據的佐證，需要謹慎看待。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有任何臨床試驗或文獻直接研究此疾病，證據等級為 L5。
- 水楊酸類可能加重冠狀動脈痙攣，機轉上存在反向風險，不宜推進。

**若要推進需要：**
- 詳細的作用機轉資料，並釐清對冠狀動脈痙攣的實際影響
- 針對變異型心絞痛的前臨床或觀察性研究，驗證安全性與療效
- 評估外用劑型與心血管適應症之間的給藥途徑相容性
- 完整的安全性與禁忌症資料，特別是對心血管與腎功能的影響
