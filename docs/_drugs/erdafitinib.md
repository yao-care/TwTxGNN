# Erdafitinib：從泌尿道上皮癌到肺動脈高壓

## 一句話總結

Erdafitinib（盼樂）是一種口服 FGFR 酪胺酸激酶抑制劑，原本用於治療帶有 FGFR3 基因變異的局部晚期或轉移性泌尿道上皮癌。
TxGNN 模型預測它可能對**肺動脈高壓 (Pulmonary Hypertension)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

Erdafitinib 是 pan-FGFR 酪胺酸激酶抑制劑，可阻斷 FGFR 訊號傳遞。在原適應症中，它針對帶有 FGFR3 變異的泌尿道上皮癌細胞發揮作用。（目前缺乏 DrugBank 的詳細作用機轉資料，以上為依藥物類別所作的說明。）

文獻上曾有人提出 FGF/FGFR 訊號與肺血管重塑有關，而血管重塑是肺動脈高壓的核心病理變化之一，這是此預測在機轉上唯一的合理連結。

不過，這個連結目前只是推測，沒有任何臨床證據。原適應症（癌症）與肺動脈高壓在疾病性質上差異很大，且抑制 FGFR 也可能帶來心血管與血管方面的安全疑慮，甚至可能與預期方向相反。此預測應視為待驗證的假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 肺動脈高壓這項預測僅有模型分數（證據等級 L5），沒有臨床試驗與文獻，機轉連結也只是推測。
- FGFR 抑制可能帶來心血管與血管安全疑慮，在缺乏證據前不宜推進。

**若要推進需要：**
- 取得詳細的作用機轉資料（MOA），並釐清 FGFR 抑制在肺血管重塑中是有益還是有害
- 進行前臨床研究（如肺動脈高壓動物模型），評估療效與血管安全性
- 補充完整的安全性資料（警語、禁忌症），特別是心血管相關風險
- 評估與肺動脈高壓常用藥物併用時的交互作用
