# Brodalumab：從斑塊性乾癬到絛蟲樣線蟲感染（類圓線蟲症）

## 一句話總結

Brodalumab（立美西膚）是一種 IL-17 受體 A（IL-17RA）阻斷劑，原本用於斑塊性乾癬等免疫相關皮膚與關節疾病。
TxGNN 模型預測它可能對**類圓線蟲症 (Strongyloidiasis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，且機轉方向反而不利。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（DrugBank 未收錄 MOA）。依已知資訊，Brodalumab 是針對 IL-17RA 的單株抗體，可同時阻斷多種 IL-17 家族細胞激素的訊號。

IL-17 訊號對黏膜免疫與抗寄生蟲（含蠕蟲）的宿主防禦有貢獻。阻斷此路徑預期會**削弱**宿主防禦，而非幫助清除感染。因此，這項預測缺乏臨床證據，機轉方向也不利，較可能只是模型的統計關聯，而非真正可行的治療方向。

## 安全性考量

- **知識圖譜標示的潛在禁忌疾病**：克隆氏症 (Crohn disease)、發炎性腸道疾病 (inflammatory bowel disease)、克隆氏結腸炎 (Crohn's colitis)。此資訊來自知識圖譜的藥物－疾病關聯，並非仿單原文，須對照原廠仿單確認。
- **藥物交互作用**：共查得 68 筆，以下為其中主要項目：
  - **嚴重 (Major)**：Adalimumab、Baricitinib、Certolizumab pegol、卡介苗（BCG, Tice 株活菌）。多與免疫抑制疊加、感染風險或活性疫苗有關。
  - **中度 (Moderate)**：Roflumilast、Alefacept、Alemtuzumab、Anakinra、Canakinumab、破傷風類毒素疫苗、炭疽疫苗、霍亂活疫苗等。
  - **輕微 (Minor)**：各種鋅鹽（醋酸鋅、葡萄糖酸鋅、硫酸鋅、氯化鋅）。
- 其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 該預測只有模型分數支持，沒有臨床試驗與文獻，證據等級為 L5。
- IL-17RA 阻斷可能削弱抗蠕蟲免疫，機轉方向不利，且有感染相關的安全性顧慮。

**若要推進需要：**
- 補充 Brodalumab 的作用機轉資料（MOA）。
- 先做 IL-17 訊號在類圓線蟲感染中角色的前臨床或機轉研究，確認是否有任何潛在益處。
- 在有支持性證據之前，不建議投入臨床開發。
- 另可評估排名第 2 的眼部發炎類適應症，但現有文獻偏向風險訊號，需更多資料才能判斷。
