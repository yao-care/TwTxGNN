# Cetuximab：從轉移性直腸結腸癌到兒童支氣管腺瘤／類癌

## 一句話總結

Cetuximab（爾必得舒）是一種抗 EGFR 單株抗體，原本用於 RAS 原生型轉移性直腸結腸癌及頭頸部癌。
TxGNN 模型預測它可能對**兒童支氣管腺瘤／類癌 (Bronchial adenomas/carcinoids, childhood)** 有效，
但目前**沒有臨床試驗，也沒有相關文獻**支持，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 cetuximab 是針對表皮生長因子受體（EGFR）的單株抗體，透過阻斷 EGFR 訊號傳導來抑制腫瘤細胞增生。它在大腸直腸癌與頭頸部鱗狀細胞癌中的療效已獲證實。

從機轉上看，若支氣管腺瘤／類癌的生長依賴 EGFR 訊號，阻斷 EGFR 理論上可能有作用。然而，目前沒有任何臨床試驗或文獻將 cetuximab 與這類腫瘤連結起來，這個關聯完全來自 TxGNN 模型預測。原適應症以消化道及頭頸部的上皮性癌症為主，與兒童支氣管神經內分泌腫瘤的疾病生物學差異不小，相似度尚待評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測僅有模型分數支持，沒有任何臨床試驗或文獻佐證，證據等級為 L5。
- 目前缺乏機轉資料，也不清楚腫瘤是否依賴 EGFR 訊號，因此不建議推進。

**若要推進需要：**
- 補充詳細的作用機轉資料，並確認兒童支氣管腺瘤／類癌是否表現 EGFR。
- 進行系統性文獻檢索與前臨床研究，以建立最基本的生物學證據。
- 評估兒童族群的安全性與劑量，並與肺部或神經內分泌腫瘤專科討論臨床需求。
- 同一份預測清單中，「囊性腫瘤 (cystic neoplasm)」與「癌前病變 (pre-malignant neoplasm)」各有早期臨床試驗和文獻（證據等級 L3），可視為較優先的研究方向。
