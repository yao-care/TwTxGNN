# Avelumab：從默克細胞癌到 HHV-8 相關腫瘤

## 一句話總結

Avelumab 是一種 PD-L1 阻斷抗體，原本用於轉移性默克細胞癌、晚期腎細胞癌（併用 axitinib）及泌尿道上皮癌的維持療法。
TxGNN 模型預測它可能對**人類疱疹病毒 8 型相關腫瘤 (human herpesvirus 8-related tumor)** 有效，
但目前**沒有臨床試驗和文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Avelumab 是 PD-L1 阻斷抗體，可解除腫瘤對 T 細胞的免疫抑制，恢復抗腫瘤免疫反應。

HHV-8 相關腫瘤（例如卡波西氏肉瘤）由病毒驅動，且可能表現 PD-L1，因此在機轉上有可能適用。
此外，Avelumab 已核准用於默克細胞癌，而默克細胞癌同樣與病毒（默克細胞多瘤病毒）相關，兩者在免疫機轉上有部分類比性。

但這個推論**尚未經任何臨床或文獻資料驗證**，目前僅能視為假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高（99.97%），但沒有任何臨床試驗或文獻佐證，證據等級僅為 L5，不足以支持推進。
- 排名前 8 的預測多缺乏合理機轉；相對而言，排名 9、10 的泌尿道上皮癌亞型因可由現有適應症外推，較值得優先作為研究問題。

**若要推進需要：**
- 補齊 Avelumab 的作用機轉資料（MOA）
- 搜尋 HHV-8 相關腫瘤（如卡波西氏肉瘤）中 PD-L1 表現及免疫檢查點抑制劑的文獻與臨床試驗
- 評估是否改以泌尿道上皮癌亞型（前列腺尿道、腎盂）為優先驗證對象
- 針對目標族群（如 HIV 相關或免疫低下病人）建立安全性評估，並留意與 lenalidomide、pomalidomide、thalidomide 併用的風險
