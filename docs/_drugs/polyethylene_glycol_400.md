# Polyethylene glycol 400：從便秘到支氣管炎

## 一句話總結

Polyethylene glycol 400（聚乙二醇 400）是一種親水性高分子，在台灣原本用於成人及八歲以上兒童便秘的症狀治療，也常作為軟膏基劑與人工淚液的成分。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個預測，僅屬模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Polyethylene glycol 400 是一種惰性的親水性聚合物，主要用作賦形劑、潤滑劑，以及滲透性或保濕成分。在便秘適應症中，其作用來自滲透性緩瀉；在眼用與軟膏製劑中，則作為保濕與基劑成分。

目前找不到與支氣管炎相關的已確立藥理機轉。便秘與支氣管炎在病理與治療標的上沒有明顯關聯，因此這項預測缺乏臨床與機轉證據支持。高預測分數較可能反映知識圖譜中的統計關聯，而非真實的療效訊號。

另一個被預測的適應症是**先天性魚鱗癬樣紅皮症 (Congenital Ichthyosiform Erythroderma)**，預測分數為 99.10%。PEG 400 的保濕特性在外用基劑中理論上可幫助皮膚補水，但它對角質化缺陷沒有疾病修飾作用，此連結同樣僅屬推測，也沒有試驗或文獻佐證。

## 安全性考量

- **知識圖譜標示的禁忌相關疾病**（來自 TxGNN 知識圖譜的藥物－疾病關聯，非仿單內容），主要包括：
  - 腸道相關：腸阻塞、腸梗阻、麻痺性腸阻塞、毒性巨結腸、幽門狹窄、闌尾炎
  - 腎臟與電解質：腎臟疾病、無尿、鉀缺乏、高血鈣、腎鈣質沉著症、磷代謝異常
  - 心血管與代謝：高血壓、鬱血性心衰竭、心血管疾病、糖尿病、糖尿病酮酸中毒、高血糖
  - 其他：癲癇、甲狀腺功能亢進（含 Graves 病）、閉角型青光眼、眼部感染、結膜炎

  這些關聯不一定代表單方 PEG 400 的正式禁忌，使用前仍須對照各製劑的原廠仿單。
- **藥物交互作用**：本次資料中查無交互作用紀錄。

其餘警語與禁忌症資訊請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型，沒有臨床試驗與文獻，證據等級為 L5。
- PEG 400 是惰性賦形劑與滲透性成分，與支氣管炎之間沒有已知的機轉連結。

**若要推進需要：**
- 補齊作用機轉資料，並評估是否存在與呼吸道發炎相關的生物學路徑
- 進行系統性文獻檢索，確認是否有任何前臨床或臨床訊號
- 釐清給藥途徑（口服、吸入或其他）與支氣管炎治療的可行性
- 若有初步訊號，再設計前臨床研究驗證，之後才考慮臨床試驗
