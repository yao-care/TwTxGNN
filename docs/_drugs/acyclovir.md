# Acyclovir：從單純疱疹感染到尋常疣（Common Wart）

## 一句話總結

Acyclovir 是核苷類抗病毒藥物，原本用於單純疱疹、帶狀疱疹與水痘等疱疹病毒感染。
TxGNN 模型排名第一的預測是「點狀上皮角結膜炎」，但該預測缺乏實質證據。
本報告改以證據最完整的**尋常疣 (Common Wart)** 作為主要評估對象，目前有 **4 個臨床試驗**與 **20 篇文獻**支持這個方向，其中包含 1 個 Phase 2/3 隨機對照試驗。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Acyclovir 經病毒胸苷激酶磷酸化後，抑制病毒 DNA 聚合酶，是疱疹病毒感染的標準抗病毒藥物。

尋常疣由人類乳突病毒（HPV）引起。HPV 是 DNA 病毒，但**本身不具備胸苷激酶**，因此 Acyclovir 的傳統活化途徑是否適用仍有疑問。
目前文獻提出的可能解釋包括局部免疫刺激或其他非典型抗病毒作用，這些都尚未被證實。

雖然機轉未明，臨床上已有多項病灶內注射 Acyclovir 治療疣的試驗與研究，並與冷凍治療、維生素 D3、念珠菌抗原、B 型肝炎疫苗等療法比較，因此這個方向值得進一步驗證。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
尋常疣已有一項 Phase 2/3 隨機對照試驗與多項比較性研究，另有 2026 年發表的 RCT，方向一致。但試驗規模小（每項約 40–92 人），且多數狀態為「未知」。HPV 缺乏胸苷激酶，機轉不明確，並且病灶內注射為仿單外使用。其他預測（如點狀上皮角結膜炎、C 型肝炎肝硬化、念珠菌外陰陰道炎、嗜酸性膿疱性毛囊炎、丘疹性蕁麻疹）僅有模型預測或機轉上不合理，建議暫緩（Hold）。「COVID-19 後遺症」與「眼眶區域疾病」目前僅屬研究問題階段。

**若要推進需要：**
- 確認 NCT06261684 與 JAMA Dermatol 等相關試驗的完成狀態與主要結果
- 取得 Acyclovir 對 HPV 疣的作用機轉資料（MOA）
- 設計較大樣本、安慰劑或標準療法對照的多中心試驗，並評估復發率
- 釐清病灶內注射的劑量、製劑與安全性，及台灣適應症外使用的法規路徑
- 針對腎功能不全與合併用藥族群，制定安全性監測計畫
