# Alprostadil：從週邊動脈阻塞疾病到主動脈畸形

## 一句話總結

Alprostadil（前列腺素 E1）原本用於改善週邊動脈阻塞疾病症狀，以及在先天性心臟缺損新生兒中暫時維持動脈導管開放。
TxGNN 模型預測它可能對**主動脈畸形 (Aortic Malformation)** 有效，
目前**無臨床試驗登記**，但有 **8 篇文獻**支持這個方向，多為世代研究、病例報告與回顧。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。依一般藥理學，Alprostadil（PGE1）活化 EP 受體並提高 cAMP，使動脈導管平滑肌鬆弛，讓導管維持開放。

主動脈畸形（如主動脈弓中斷、主動脈狹窄）常屬於「依賴動脈導管」的病變，體循環血流需靠導管維持。現行台灣仿單已涵蓋主動脈弓中斷與主動脈狹窄等先天性心臟缺損，因此這項預測與既有用途高度重疊，較像是把既有適應症的範圍以疾病名稱重新歸類，而非全新的療效方向。

文獻中也有實際案例：主動脈弓中斷（type B）新生兒使用 alprostadil 及 alprostadil alfadex 維持導管開放後接受一期修復，另有大血管轉位的治療回顧，說明術前維持導管通暢的角色。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：新生兒呼吸窘迫症候群、急性呼吸窘迫症候群、低血壓、血液凝固疾病、鐮刀型貧血、肺部疾病、多發性骨髓瘤、幽門狹窄、陰莖異常勃起、佩洛尼氏症、白血病、血小板增多症、真性紅血球增多症等（此為知識圖譜關聯，非仿單原文）。
- **文獻中的安全訊號**：長期輸注前列腺素 E1 的新生兒曾有胃出口阻塞（幽門肥厚性狹窄）與偽性巴特氏症候群的病例報告，使用時需留意。
- **藥物交互作用**：共查得 59 筆，其中中度等級包括 Canagliflozin、Dapagliflozin、Empagliflozin、Ertugliflozin、Lorcaserin、Sapropterin；其餘如 Morphine、Metformin、Omeprazole、Prednisone 等等級未明。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
此預測與台灣現有仿單（主動脈弓中斷、主動脈狹窄等依賴導管的先天性心臟缺損）高度吻合，且有病例報告與臨床回顧支持，證據等級為 L3。但缺乏臨床試驗與 MOA 資料，且新生兒長期輸注有明確安全疑慮，故需設定防護條件。

**若要推進需要：**
- 補充 DrugBank 作用機轉資料
- 釐清「主動脈畸形」與現有仿單適應症的範圍差異，確認是否屬新適應症
- 建立新生兒輸注的監測計畫（呼吸暫停、血壓、胃出口阻塞、電解質）
- 以較高品質的比較性研究補強證據

**其他預測的備註：** 其餘預測（如先天性三尖瓣狹窄、三尖瓣發育不全等）僅有模型預測而無臨床證據，建議為 Hold；「心臟中隔缺損」為 Research Question（L4）；「三尖瓣脫垂」與「地方性甲狀腺腫」缺乏合理機轉，可能為知識圖譜的預測假象。
