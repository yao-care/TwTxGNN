# Potassium Iodide (碘化鉀) - 藥師評估報告

## 一句話總結

碘化鉀是一種具有祛痰、抗真菌及甲狀腺保護作用的藥物,TxGNN預測其可用於鼻腔疾病治療,已有文獻證據支持其對真菌性鼻竇炎的療效。

> **查核加註（2026-10-03）**：「皮膚消毒」「絲狀菌感染」是碘＋碘化鉀（濃碘酊，衛署藥製字第033308號）與碘＋碘化鉀＋水楊酸（碘楊酸外用液劑，衛署藥製字第044330號）複方的適應症，殺菌與抗黴菌作用主要來自碘與水楊酸；「預防甲狀腺腫」來自已於 2005-06-16 註銷的許可證（內衛藥輸字第000502號）。現行單方碘化鉀錠（衛署藥製字第056668號）核准的是輻射緊急事故時保護甲狀腺。原文保留。依據：[衛福部食藥署開放資料「全部藥品許可證資料集」（資料集 36，2026-09-29）](https://data.fda.gov.tw/data/opendata/export/36/json)。

## 為什麼這個預測合理?

### 鼻腔疾病預測分析 (TxGNN Score: 0.9995, Rank: 1593)

1. **抗真菌活性**: 碘化鉀具有已知的抗真菌活性,特別是對孢子絲菌病和接合菌病
2. **黏膜作用**: 碘離子可促進黏液分泌和清除
3. **免疫調節**: 可能具有增強局部免疫反應的作用
4. **歷史應用**: 傳統上用於治療深部真菌感染

<!-- review:begin potassium-iodide-antifungal-2026-10-03 -->

> **查核加註（2026-10-03）**：碘化鉀用於孢子絲菌病有依據（WHO 基本藥物清單列為抗真菌藥），但其抗真菌作用機轉尚未確定；所查來源只列孢子絲菌病，沒有接合菌病。原文保留。依據：[PubChem：Potassium iodide（CID 4875），Pharmacology and Biochemistry › Mechanism of Action（引自 AHFS Drug Information 2005）](https://pubchem.ncbi.nlm.nih.gov/compound/4875)。

<!-- review:end potassium-iodide-antifungal-2026-10-03 -->

### 急性喉咽炎預測分析 (TxGNN Score: 0.9995, Rank: 1664)

1. **祛痰作用**: 碘化鉀可增加呼吸道分泌物,有助於痰液排出
2. **抗菌特性**: 碘具有廣譜抗菌作用
3. **黏膜保護**: 可能有助於黏膜修復

## 安全性考量

### 已知安全性資訊

1. **甲狀腺功能影響**: 長期高劑量可能導致甲狀腺功能異常
2. **碘過敏**: 對碘過敏者禁用
3. **妊娠哺乳**: 可穿透胎盤,需謹慎使用
4. **腎功能**: 腎功能不全者需調整劑量

### 藥物交互作用 (重要)

碘化鉀有多項重要藥物交互作用,需特別注意:

**Major (主要) 交互作用**:

| 交互藥物 | 機制/風險 |
|----------|-----------|
| ACE抑制劑 (Benazepril, Captopril, Enalapril等) | 增加高血鉀風險 |
| ARB類 (Losartan, Valsartan, Irbesartan等) | 增加高血鉀風險 |
| Eplerenone | 嚴重高血鉀風險 |
| Trimethoprim | 高血鉀風險 |

**Moderate (中等) 交互作用**:

| 交互藥物 | 機制/風險 |
|----------|-----------|
| NSAIDs (Ibuprofen, Diclofenac, Naproxen等) | 可能增加血鉀 |
| Lithium | 可能影響甲狀腺功能 |
| I-131, I-123 | 干擾放射碘攝取 |
| Aliskiren | 增加高血鉀風險 |

## 結論與下一步

### 整體評估

| 評估項目 | 鼻腔疾病 | 急性喉咽炎 |
|----------|----------|------------|
| 證據等級 | L3 (病例報告) | L5 (僅預測) |
| 機制合理性 | 高 (抗真菌) | 中 (祛痰) |
| 臨床可行性 | 中 (限真菌性) | 低 |
| 建議優先順序 | 中 | 低 |

### 建議

**鼻腔真菌感染**:
1. **適用族群**: 真菌性鼻竇炎,特別是接合菌病、腐黴病
2. **合併治療**: 建議與其他抗真菌藥物(如itraconazole)合併使用
3. **進一步研究**: 需要前瞻性臨床試驗評估療效和安全性
4. **臨床定位**: 作為難治性真菌性鼻部感染的輔助治療選項

**急性喉咽炎**:
- 缺乏直接證據支持
- 不建議作為主要治療選項

### 用藥監測建議

1. **甲狀腺功能**: 長期使用需定期監測TSH
2. **血鉀濃度**: 特別是合併使用高血鉀風險藥物時
3. **腎功能**: 定期監測肌酐清除率

### 限制說明

- 鼻腔真菌感染的證據主要來自病例報告
- 缺乏大規模隨機對照試驗
- 獸醫研究結果不能直接外推至人類
