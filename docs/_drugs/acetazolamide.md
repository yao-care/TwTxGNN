# Acetazolamide：從青光眼到運動誘發惡性高熱

## 一句話總結

Acetazolamide（乙醯唑胺）是碳酸酐酶抑制劑，原本用於青光眼，並作為水腫、癲癇的輔助治療。
TxGNN 模型預測它可能對**運動誘發惡性高熱 (Exercise-induced Malignant Hyperthermia)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Acetazolamide 是碳酸酐酶抑制劑，會造成利尿與代謝性酸中毒，其在青光眼、水腫與癲癇的療效已被證實。

然而，就運動誘發惡性高熱而言，目前沒有臨床或文獻證據將兩者連結。這個關聯完全來自 TxGNN 的模型預測，機轉上是否適用尚無法確認，應視為待驗證的假說。

**理由：**
此預測僅來自模型分數，沒有臨床試驗、文獻或明確的機轉支持（證據等級 L5），目前不足以推進。

**若要推進需要：**
- 補齊 Acetazolamide 的作用機轉資料，並分析其與惡性高熱病理機轉（如骨骼肌鈣離子調控異常）是否有關聯
- 進行系統性文獻回顧與前臨床研究，確認是否有任何生物學合理性
- 評估酸中毒、電解質變化對此類患者的潛在風險
- 另可留意同一模型輸出中的**心肌病變／心衰竭**方向（證據等級 L4，有間接的個案與前臨床資料），其優先度可能高於本適應症，但仍屬研究假說階段
