# Homatropine methylbromide：從消化性潰瘍與胃酸過多到胃十二指腸炎

## 一句話總結

Homatropine methylbromide（甲溴化后瑪托品）是一種抗膽鹼（副交感神經抑制）藥物，在台灣主要用於胃酸過多、胃痛、胃及十二指腸潰瘍與胃腸痙攣。
TxGNN 模型預測它可能對**胃十二指腸炎 (Gastroduodenitis)** 有效，但目前**沒有任何臨床試驗或文獻**支持，且這項預測與既有適應症高度重疊，並非真正的新用途。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，甲溴化后瑪托品是作用於周邊的抗膽鹼（抗蕈毒鹼）藥物，可減少胃酸分泌並緩解胃腸道平滑肌痙攣。

台灣已核准的含此成分產品（多為複方）適應症包括胃炎、胃及十二指腸潰瘍、胃酸過多與幽門痙攣。胃十二指腸炎屬於同一類上消化道發炎問題，因此模型的預測在機轉與標示上都說得通。

需要注意的是，這個預測與既有適應症大幅重疊，更像是對現有用途的再確認，而非真正的藥物再利用訊號。

另一個預測是**馬尾症候群 (Cauda equina syndrome，分數 99.10%)**，但未發現合理的機轉連結。馬尾症候群是神經根受壓迫造成的外科急症，抗膽鹼藥最多只能影響次要的膀胱症狀，無法治療根本原因，還可能加重尿滯留。此預測缺乏任何證據支持，不建議推進。

**決策：Hold**

**理由：**
- 胃十二指腸炎的預測與已核准的胃炎、胃十二指腸潰瘍適應症高度重疊，並非新的用途，且沒有任何臨床試驗或文獻佐證。
- 馬尾症候群的預測缺乏機轉依據，也沒有證據，不具推進價值。

**若要推進需要：**
- 補充詳細的作用機轉資料（MOA）。
- 確認台灣核准適應症是否已涵蓋胃十二指腸炎，以判斷是否需要另行申請。
- 針對胃十二指腸炎收集臨床試驗或文獻證據，特別是單方與複方的療效差異。
- 取得原廠仿單的警語與禁忌症，完善安全性評估。
