# Belimumab：從全身性紅斑性狼瘡到原發性血小板釋放障礙

## 一句話總結

Belimumab（奔麗生）是一種 BLyS（BAFF）抑制劑，原本與標準治療併用於高疾病活性的自體免疫抗體陽性全身性紅斑性狼瘡（5 歲以上）及活動性狼瘡腎炎（成年）。
TxGNN 模型預測它可能對**原發性血小板釋放障礙 (primary release disorder of platelets)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Belimumab 是一種抑制 BLyS（BAFF）的生物製劑，可降低 B 細胞存活與自體抗體產生，在自體免疫型疾病（如狼瘡）中的療效已被證實。

然而，原發性血小板釋放障礙是遺傳性的血小板功能缺陷，並非由 B 細胞自體免疫所驅動，與 Belimumab 的作用路徑之間沒有明確的機轉連結。因此這項預測目前只能視為模型輸出的假說，缺乏臨床或文獻佐證。

另外，其他預測結果（如 pseudo-von Willebrand 病、Glanzmann 血小板無力症、胎兒與新生兒同種免疫性血小板低下症、重度非增殖性糖尿病視網膜病變、體染色體顯性巨血小板低下症）同樣沒有實證支持。其中僅「胎兒與新生兒同種免疫性血小板低下症」在概念上與抗體生成有些關聯，但孕期使用的安全性疑慮使其仍停留在假說階段。

## 安全性考量

- **藥物交互作用**：已查詢到 69 筆潛在交互作用，主要包括：
  - **嚴重 (Major)**：Adalimumab、Baricitinib、Certolizumab pegol、卡介苗（BCG，活菌株）
  - **中度 (Moderate)**：Roflumilast、Azathioprine、Alemtuzumab、Anakinra、Canakinumab、Alefacept、破傷風類毒素疫苗、炭疽疫苗、腺病毒疫苗、霍亂活疫苗等
  - **輕微 (Minor)**：各種鋅鹽（醋酸鋅、葡萄糖酸鋅、硫酸鋅、氯化鋅）

  整體而言，與其他免疫抑制生物製劑／JAK 抑制劑併用，以及接種活性減毒疫苗，需特別留意。

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 六個預測適應症皆無臨床試驗或文獻支持，證據等級僅為 L5，且排名第一的預測在機轉上缺乏合理連結。

**若要推進需要：**
- 補齊 Belimumab 的作用機轉資料，並重新評估其與血小板功能障礙的機轉關聯
- 進行系統性文獻與試驗檢索，確認是否有任何相關的前臨床或臨床證據
- 若後續考慮與抗體介導的血小板疾病（如同種免疫性血小板低下症）相關的方向，需先釐清孕期使用的安全性
- 在取得任何實證前，不建議進入臨床開發或適應症擴增評估
