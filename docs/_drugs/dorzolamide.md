## 鹽酸多佐胺 (Dorzolamide)：碳酸酐酶抑制劑 → 頭皮單純性毛髮稀少症 (hypotrichosis simplex of the scalp)
{: .text-alpha }

## 一句話總結

Dorzolamide（鹽酸多佐胺）是一種碳酸酐酶抑制劑，台灣已有多張許可證。
TxGNN 模型預測它可能對**頭皮單純性毛髮稀少症 (hypotrichosis simplex of the scalp)** 有效，
但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Dorzolamide 作用於碳酸酐酶（包括 CA1、CA7、CA12、CA14），主要以眼用製劑形式使用，局部給藥的全身暴露量低。

頭皮單純性毛髮稀少症是一種遺傳性毛囊疾病。目前看不出碳酸酐酶抑制與毛囊發育或毛髮生長之間有合理的機轉關聯。這項預測較可能是模型從資料關聯中推得的結果，缺乏生物學上的支持。

此外，目前也沒有任何針對這個疾病的臨床試驗或文獻。在有進一步機轉或實驗證據之前，這項預測只能視為假說。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數，沒有任何臨床試驗或文獻直接研究此疾病，證據等級為 L5。
- 碳酸酐酶抑制與毛囊疾病之間缺乏合理的機轉關聯，局部給藥的全身暴露量也低。

**若要推進需要：**
- 補充 Dorzolamide 與毛囊生物學之間的機轉證據，例如細胞或動物模型研究。
- 確認碳酸酐酶在毛囊發育中是否扮演角色。
- 評估眼用劑型是否適合頭皮給藥，包括劑型與給藥途徑的可行性。
- 取得任何針對此疾病的臨床或文獻證據後，再重新評估。
