## Guselkumab：從潰瘍性結腸炎／克隆氏症到藥物誘發性骨質疏鬆
{: .text-alpha }

## 一句話總結

Guselkumab（特諾雅）是一種 IL-23 p19 單株抗體，在台灣原本用於治療中至重度活動性潰瘍性結腸炎與克隆氏症，也用於乾癬等自體免疫疾病。
TxGNN 模型預測它可能對**藥物誘發性骨質疏鬆 (Drug-induced Osteoporosis)** 有效。
目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，Guselkumab 會選擇性結合 IL-23 的 p19 次單位，阻斷 IL-23/Th17 發炎路徑，因此能治療乾癬、潰瘍性結腸炎、克隆氏症等免疫媒介疾病。

IL-23/IL-17 訊號可能影響破骨細胞生成，所以理論上可能與骨流失有關。不過這只是推測，並無臨床或文獻證據。

原適應症（發炎性腸道疾病、乾癬）屬於免疫發炎性疾病，與藥物誘發性骨質疏鬆在病因上差異大。後者主要由藥物（如類固醇）直接影響骨代謝所致，兩者的關聯性目前仍待驗證。

## 安全性考量

- **藥物交互作用**：已查得 136 筆交互作用紀錄，主要如下。
  - **嚴重 (Major)**：Adalimumab
  - **中度 (Moderate)**：Simvastatin、Warfarin、Apixaban、Rivaroxaban、Dicoumarol、Tacrolimus、Theophylline、Aminophylline、Roflumilast、Lidocaine、Fentanyl、Hydrocodone、Nifedipine、破傷風類毒素疫苗
  - **輕微 (Minor)**：各種鋅鹽類（硫酸鋅、醋酸鋅、葡萄糖酸鋅、氯化鋅）

其他警語與禁忌症請參考原廠仿單。使用前應依一般指引評估感染風險，並篩檢結核病。

## 結論與下一步

**決策：Hold**

**理由：**
- 這個預測只來自 TxGNN 模型（分數 0.9984），沒有任何臨床試驗或文獻佐證，證據等級為 L5。
- 機轉連結僅是推測，建議暫緩投入。

**若要推進需要：**
- 前臨床研究，例如驗證 IL-23 阻斷對破骨細胞與骨代謝的影響（動物模型或細胞實驗）。
- 回溯性真實世界資料，觀察使用 Guselkumab 的病人（尤其是長期使用類固醇者）骨密度或骨折風險的變化。
- 釐清 IL-23 路徑在藥物誘發性骨質疏鬆中的角色，並建立可驗證的假說。
- 詳細的作用機轉資料與長期骨骼安全性資料。

**補充說明：**同一模型的其他高分預測中，乾癬與潰瘍性結腸炎已是核准適應症（有 Phase 3 證據），不屬於真正的藥物再利用。其餘預測（如糖尿病視網膜病變、續發性腎性骨病變等）同樣僅有模型預測，無實際研究支持。
