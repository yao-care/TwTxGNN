# Cytarabine：從急性骨髓性白血病到小細胞肺癌

## 一句話總結

Cytarabine 是急性骨髓性白血病（AML）標準化療方案中的核心成分，台灣 cytarabine 單方許可證核准「急性顆粒白血病及其他急性白血病」（衛署藥輸字第001879號）與「抗腫瘤劑」（衛署藥輸字第025603號、衛部藥輸字第028975號）。
TxGNN 模型預測它可能對**小細胞肺癌 (Small Cell Lung Carcinoma)** 有效，但目前**無臨床試驗登記**，僅有 **20 篇文獻**，且多為非小細胞肺癌、腦膜轉移或一般化療藥物回顧，屬間接證據。

<!-- review:begin cytarabine-original-indication-cll-summary-2026-10-16 -->

> **查核更正（2026-10-16）**：原寫「台灣目前以併用藥物（如 midostaurin、quizartinib、venetoclax）的許可證適應症呈現。」。midostaurin、quizartinib、venetoclax 是各自的許可證，cytarabine 只是其中的併用藥；台灣 cytarabine 本身有 3 張有效單方許可證，適應症為「急性顆粒白血病及其他急性白血病」與「抗腫瘤劑」。依據：[衛福部食藥署開放資料「全部藥品許可證資料集」（資料集 36，檔案 36_5.json，2026-09-29）](https://data.fda.gov.tw/data/opendata/export/36/json)。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，cytarabine 是嘧啶核苷類似物，屬 S 期特異性的抗代謝藥物，可抑制 DNA 合成。小細胞肺癌增殖快速，機轉上理論上可能對這類藥物敏感。

原適應症為血液惡性腫瘤，新預測為實體腫瘤，兩者的關聯主要建立在「快速增殖腫瘤對抗代謝藥物敏感」的推論上。不過，文獻也指出 cytarabine 對多數實體腫瘤活性有限，這是此預測的主要疑慮。

現有文獻中，直接與小細胞肺癌相關者只有一篇高劑量 cytarabine 的早期報告（1987 年，無摘要），其餘多為非小細胞肺癌的 cisplatin 併用 cytarabine 研究，反應率偏低。因此證據屬間接。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前無臨床試驗，文獻多為非小細胞肺癌或一般化療回顧，與小細胞肺癌直接相關的證據極少，證據等級為 L4。
- 非小細胞肺癌的歷史研究中反應率偏低（約 14–18%），且高劑量方案毒性明顯，風險效益不明確。

**若要推進需要：**
- 取得 cytarabine 的作用機轉資料（MOA），補足機轉分析。
- 針對小細胞肺癌進行系統性文獻回顧，特別是 1987 年高劑量 cytarabine 研究的全文。
- 先以體外或動物模型驗證 cytarabine 對小細胞肺癌的活性，再評估是否設計早期臨床試驗。
- 評估骨髓抑制等毒性的風險控管計畫。

**其他預測適應症（供參考）：** 原始預測中另有原發性肺淋巴瘤、神經母細胞瘤等，其中神經母細胞瘤有體外證據與 3 項未能確認含 cytarabine 的試驗，可列為研究問題；其餘多為僅有模型預測的項目。
