# Posaconazole：從侵入性黴菌感染到肺囊蟲病（Pneumocystosis）

## 一句話總結

Posaconazole 是三唑類抗黴菌藥，原本用於侵入性麴菌病的第二線治療，以及高危險族群的侵入性黴菌感染預防。
TxGNN 模型預測它可能對**肺囊蟲病 (Pneumocystosis)** 有效，但目前僅有 **1 個相關臨床試驗**（使用的是另一種藥物）和 **5 篇間接相關文獻**，沒有直接的 posaconazole 證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Posaconazole 屬於三唑類抗黴菌藥，一般認為它抑制黴菌的 CYP51（羊毛固醇 14-α 去甲基酶），阻斷麥角固醇合成，在侵入性麴菌病和黴菌感染預防中的療效已被證實。

肺囊蟲病與原適應症都發生在免疫低下的族群（如血液惡性腫瘤、造血幹細胞移植患者），臨床上屬於同一類高風險人群，這是預測在臨床情境上的關聯。

但在機轉上，支持相當薄弱。*Pneumocystis jirovecii* 細胞膜幾乎不含麥角固醇（使用類膽固醇的固醇），因此阻斷麥角固醇合成的azole 機轉只能提供間接、偏推測性的支持。高分數主要來自模型的網絡關聯，不代表已有藥理證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型，證據等級為 L4。唯一的臨床試驗用的是另一種藥物（rezafungin），文獻也無直接的 posaconazole 數據。
- 肺囊蟲缺乏麥角固醇，azole 類的作用機轉本身就不支持此適應症。TMP-SMX 等已有標準治療。

**若要推進需要：**
- 補充 posaconazole 的作用機轉資料，並釐清對 *Pneumocystis* 的實際活性。
- 進行體外或動物模型的前臨床研究，確認是否有任何抑制作用。
- 搜尋是否有 posaconazole 用於肺囊蟲病預防或治療的直接臨床報告（含病例報告、回溯性研究）。
- 在有任何直接證據前，不建議投入臨床開發。
