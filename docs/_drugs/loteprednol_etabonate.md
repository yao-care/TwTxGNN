## Loteprednol etabonate：從眼部類固醇反應性發炎到結膜濾泡增生症
{: .text-alpha }

## 一句話總結

Loteprednol etabonate（隆特明）是一種眼用局部類固醇，原本用於治療對類固醇有反應的眼部發炎，以及緩解季節性過敏性結膜炎的症狀。
TxGNN 模型預測它可能對**結膜濾泡增生症 (Conjunctival Folliculosis)** 有效，但目前**沒有臨床試驗和文獻**直接支持這個預測，僅為模型推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Loteprednol 是局部用糖皮質素（類固醇），可抑制結膜的發炎反應，在已核准的類固醇反應性眼部發炎中療效已被證實，機轉上可能對結膜的濾泡性變化有作用。

原適應症與預測新適應症同屬眼表（結膜）疾病。不過，結膜濾泡增生症常是良性、非發炎性的臨床表現，是否真有使用類固醇的必要仍有疑問。

此預測目前僅來自 TxGNN 模型，沒有臨床試驗或文獻佐證。同一批預測中還有數個相近的結膜炎項目（如慢性濾泡性結膜炎、非病毒性漿液性結膜炎），分數相同，可能反映模型對相似疾病名稱的歸納，而非獨立的證據。

## 安全性考量

- **知識圖譜標示的疾病禁忌**（來自知識圖譜的藥物－疾病禁忌關聯，非仿單原文）：高眼壓、青光眼、單純疱疹病毒角膜炎、眼部黴菌感染、病毒性眼部感染、眼結核、眼部帶狀疱疹。使用前須先排除這些情況。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自模型推論（L5），沒有任何臨床試驗或文獻直接支持。
- 結膜濾泡增生症常為良性表現，使用類固醇的臨床必要性不明，且長期使用有眼壓升高與感染風險。

**若要推進需要：**
- 取得 Loteprednol 的作用機轉資料，釐清與濾泡性病變的關聯
- 以文獻回顧確認結膜濾泡增生症的疾病定義、病因及類固醇治療的合理性
- 確認目標族群（排除感染性、病毒性病因）
- 評估眼壓監測等安全性計畫
- 若有初步證據，再規劃小規模探索性臨床研究
