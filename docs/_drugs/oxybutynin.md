# Oxybutynin：從膀胱過動症到不寧腿症候群

## 一句話總結

Oxybutynin 是一種抗膽鹼（抗毒蕈鹼）藥物，原本用於緩解膀胱神經控制不佳所造成的排尿症狀（膀胱過動症），外用劑型也用於原發性手掌多汗症。
TxGNN 模型預測它可能對**不寧腿症候群 (Restless Legs Syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Oxybutynin 是一種具有抗痙攣作用的毒蕈鹼受體拮抗劑，透過阻斷膽鹼作用來放鬆膀胱平滑肌、減少不自主收縮。

不寧腿症候群的病理主要與多巴胺系統及鐵代謝異常有關，目前沒有已知的路徑將抗毒蕈鹼作用與此疾病連結。這個預測僅來自 TxGNN 的圖譜推論，缺乏機轉上的直接支持。

更需要注意的是，抗膽鹼作用反而可能使不寧腿症狀惡化，因此此預測的合理性有限，需謹慎看待。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜，非仿單內容）：
  - 泌尿／消化道阻塞類：膀胱頸阻塞、腸阻塞、麻痺性腸阻塞、毒性巨結腸、良性攝護腺增生
  - 眼科：閉角型青光眼
  - 神經肌肉：重症肌無力及相關神經肌肉接合處疾病
  - 心血管：高血壓、冠狀動脈疾病、心臟傳導疾病、心臟驟停
  - 消化道其他：潰瘍性結腸炎、發炎性腸道疾病、胃食道逆流、食道炎、裂孔疝
  - 內分泌：甲狀腺機能亢進、葛瑞夫茲氏病
  - 肝、腎、膽囊疾病
- **藥物交互作用**：資料庫共收錄 205 筆交互作用。其中較需注意的為**重度**交互作用：氯化鉀 (Potassium chloride)、檸檬酸鉀 (Potassium citrate)。其餘多為中度，主要是其他抗膽鹼／抗痙攣藥物（如 Atropine、Hyoscyamine、Dicyclomine、Glycopyrronium、Trospium、Propantheline）及鴉片類藥物（如 Morphine、Opium），合併使用可能加重抗膽鹼副作用。

其他警語與正式禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有臨床試驗或文獻佐證，且抗膽鹼作用機轉與不寧腿症候群的病理（多巴胺、鐵代謝）無明確關聯，甚至可能惡化症狀。
- 另外兩個預測適應症（胃十二指腸炎、消化性潰瘍）同樣缺乏現代證據；消化性潰瘍僅有 1960 年代的舊文獻，且有 Oxybutynin 引起逆流性食道炎的病例報告，顯示可能對上消化道有害。

**若要推進需要：**
- 補充詳細的作用機轉（MOA）資料
- 先進行系統性文獻回顧，確認抗膽鹼藥物對不寧腿症候群的影響（是否惡化症狀）
- 若機轉上仍有支持，再設計前臨床或小規模探索性研究
- 確認給藥途徑與劑型的適配性（目前路徑相容性尚未評估）
