# Xylitol：從糖尿病代謝異常到腦膜炎球菌感染

## 一句話總結

Xylitol（木糖醇）是一種糖醇類醣質補充劑，原本用於糖尿病時的代謝異常，以及外傷、麻醉、手術後的醣類與熱能補充。
TxGNN 模型預測它可能對**腦膜炎球菌感染 (Meningococcal Infection)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 快速總覽

| 項目 | 內容 |
|------|------|
| 原適應症 | 糖尿病、高血糖時之醣類補充液、由於水份或電解質代謝作用不良引起之脫水現象、外傷刺激麻醉、手術後引起之不正常醣類代謝作用時之熱能補充 |
| 預測新適應症 | 腦膜炎球菌感染 (Meningococcal Infection) |
| TxGNN 預測分數 | 99.66% |

| 建議決策 | Hold |

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Xylitol 是一種糖醇，在臨床上作為糖尿病及手術、外傷情況下的碳水化合物能量來源。

就現有資訊來看，**無法建立 Xylitol 與腦膜炎球菌感染之間的機轉關聯**。原適應症屬於代謝與營養補充，新適應症則是由 *Neisseria meningitidis* 引起的細菌感染，目前未找到合理的抗菌或免疫調節路徑。

TxGNN 分數雖高（99.66%），但這只是模型預測，沒有臨床試驗或文獻佐證，應視為待驗證的假說，而非可行動的證據。

## 安全性考量

- **知識圖譜標示的禁忌疾病**：dental fluorosis（氟斑牙）。此資訊來自知識圖譜的藥物－疾病關聯，並非仿單文字，臨床意義需再確認。

其餘警語、禁忌症與藥物交互作用資料不足，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級僅為 L5，只有模型預測，沒有臨床試驗或文獻，且找不到合理的機轉連結。
- 藥物本身是醣類補充劑，沒有已知的抗菌或免疫作用，預測分數高不足以支持推進。

**若要推進需要：**
- 補齊 Xylitol 的作用機轉資料（MOA）。
- 以文獻回顧確認 Xylitol 與 *Neisseria meningitidis* 之間是否有任何體外或前臨床證據。
- 若有前臨床訊號，再評估注射劑型是否能達到有效的抗感染濃度與適用性。
- 釐清知識圖譜中「氟斑牙」禁忌關聯的來源與意義，並對照仿單安全性資訊。
