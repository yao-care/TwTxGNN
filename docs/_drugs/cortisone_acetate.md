# Cortisone acetate：從腎上腺皮質分泌缺乏症到斑禿

## 一句話總結

Cortisone acetate（醋酸可體松）是一種糖皮質素，在台灣原本用於腎上腺皮質分泌缺乏症、風濕性關節炎、過敏性疾病等。
TxGNN 模型預測它可能對**斑禿 (Alopecia Areata)** 有效，
目前**無臨床試驗登記**，僅有 **2 篇 1952 年的病例系列文獻**支持，證據相當有限。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cortisone acetate 是前驅藥物，在體內轉換為皮質醇 (cortisol)，屬於糖皮質素。糖皮質素具有抗發炎與免疫抑制作用。

斑禿的核心病理是自體免疫性 T 細胞攻擊毛囊。糖皮質素可抑制這類免疫攻擊，所以機轉上有其合理性。原適應症中的風濕性關節炎、過敏性疾病、皮膚病等，也都與免疫與發炎反應有關。

不過要注意：全身性使用糖皮質素治療斑禿，常見停藥後復發，且有全身性副作用。現有證據僅是 1952 年的個案層級報告，不足以支持臨床推進。

## 安全性考量

- **藥物交互作用**：資料庫查無相關交互作用資料。
- **知識圖譜顯示的潛在禁忌疾病**（來自 TxGNN 知識圖譜的藥物—疾病禁忌關聯，非仿單內容），主要包括：
  - 心血管與代謝：高血壓、高血糖
  - 神經與消化：癲癇、胃潰瘍
  - 肝腎與膽：腎臟疾病、肝臟疾病、膽囊疾病
  - 感染相關：單純皰疹病毒角膜炎、麻疹、生殖器人類乳突病毒感染、尋常疣
  - 內分泌：腦下垂體功能低下、生長激素缺乏、低促性腺激素性性腺功能低下等相關疾病

其他警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測分數雖高，但沒有任何臨床試驗，唯一的文獻是 1952 年的病例系列，且缺乏摘要與現代研究佐證。
- 全身性糖皮質素用於斑禿有復發與副作用的問題，且知識圖譜顯示多項潛在禁忌疾病。

**若要推進需要：**
- 取得完整的作用機轉資料（MOA）。
- 系統性回顧近年糖皮質素（含其他劑型與給藥途徑）治療斑禿的證據，並與現行標準治療比較。
- 評估給藥途徑的適配性（目前台灣 cortisone acetate 有效單方許可證為錠劑與懸浮注射液）。
- 如決定推進，需設計小規模探索性試驗，並納入安全性監測計畫。
