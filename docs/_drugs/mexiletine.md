## Mexiletine：從心室性心律不整到頭痛疾患
{: .text-alpha }

## 一句話總結

Mexiletine（鹽酸美克律定）是一種抗心律不整藥，原本用於治療心室性心律不整。
TxGNN 模型預測分數最高的是毛髮過多症，但該預測完全沒有證據支持。
證據相對最多的方向是**頭痛疾患 (Headache Disorder)**，目前有 **5 篇文獻**（皆為觀察性研究、病例系列或綜論，無 RCT），**無臨床試驗登記**。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。已知 Mexiletine 是一種 Class 1B 鈉離子通道阻斷劑，在心室性心律不整中的療效已被證實。

**排名第 1 的毛髮過多症**：鈉離子通道阻斷與毛髮生長之間沒有已知關聯，這個預測較可能反映知識圖譜中相近疾病術語的鄰近性，不具機轉支持。排名第 2 至 5 的預測（抗利尿不適當症候群、牙周畸形症候群、Dandy-Walker 畸形等）同樣缺乏機轉與臨床證據。

**頭痛疾患（排名第 10）及偏頭痛（排名第 6）**：鈉離子通道阻斷可能抑制神經元的異常放電與三叉神經血管系統的痛覺傳遞，因此在三叉自律神經頭痛及難治性慢性每日頭痛中有合理的生物學基礎。已有前瞻性開放標籤研究、小型病例系列與較早期報告，但沒有隨機對照試驗。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 排名最高的預測（毛髮過多症等）沒有任何臨床或文獻證據，機轉上也無合理連結，不建議推進。
- 頭痛疾患方向有生物學合理性與少量觀察性證據（L3），但皆為小型開放標籤研究或病例系列，可列為研究問題，尚不足以支持臨床推進。

**若要推進需要：**
- 補充詳細的作用機轉（MOA）資料
- 針對 SUNCT／SUNA 或難治性慢性每日頭痛設計前瞻性對照試驗
- 針對本藥的心臟傳導與心肌梗塞相關禁忌，建立篩選與監測計畫
- 評估非心臟適應症的劑量、耐受性與藥物交互作用管理
- 確認台灣仿單是否需要新增適應症，並評估與現有許可證劑型的相容性
