# Nitroxoline：從泌尿道感染到閉經

## 一句話總結

Nitroxoline（耐挫索林）是 8-羥基喹啉類的抗菌藥，原本用於尿道炎、膀胱炎、腎盂腎炎等泌尿道感染症。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，但目前**沒有任何臨床試驗與文獻**直接支持這個方向，僅屬於模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Nitroxoline 是 8-羥基喹啉類金屬螯合劑，具抗菌活性，在泌尿道感染的用途已獲證實。藥理資料另顯示它可能抑制人類甲硫胺酸胺肽酶 2（METAP2）等與血管新生及腫瘤相關的標的。

然而，現有資料中沒有任何內容把這些作用與生殖內分泌功能連結起來。閉經涉及下視丘－腦下垂體－卵巢軸或子宮結構問題，與抗菌及金屬螯合作用並無已知關聯。因此 TxGNN 的高分（99.74%）目前只能視為計算預測，機轉上的合理性並未建立。

## 結論與下一步

**決策：Hold**

**理由：**
- 本預測只有模型分數，沒有臨床試驗、文獻或機轉證據，證據等級為 L5。
- Nitroxoline 的藥理作用與閉經的病理機轉之間缺乏可辨識的關聯。

**若要推進需要：**
- 補齊作用機轉（MOA）資料，並評估其與生殖內分泌的可能關聯
- 進行系統性文獻回顧與前臨床研究，確認是否有任何支持訊號
- 若有前臨床訊號，再評估劑型（目前台灣皆為口服或原料粉）、劑量與安全性
- 若要尋找較有依據的再利用方向，可優先評估已有前臨床證據的領域（例如抗腫瘤、脂質代謝），並重新篩選候選適應症
