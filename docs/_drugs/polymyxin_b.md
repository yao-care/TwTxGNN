# Polymyxin B：從細菌感染（眼部／皮膚／耳部）到支氣管炎

## 一句話總結

Polymyxin B（多黏菌素 B）是一種多肽類抗生素，在台灣主要用於眼部、皮膚與耳部的細菌感染，多為複方製劑。
TxGNN 模型預測它可能對**支氣管炎 (Bronchitis)** 有效，但目前**沒有臨床試驗**，僅有 **12 篇文獻**，且多為病例系列、生理研究與動物模型，證據等級為 L4。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Polymyxin B 可結合革蘭氏陰性菌外膜脂多醣中的 lipid A，破壞外膜結構而殺菌。因此在機轉上，它可能適用於由多重抗藥性革蘭氏陰性菌（如綠膿桿菌、鮑氏不動桿菌）引起的氣管支氣管感染。

原適應症為眼、耳、皮膚的局部細菌感染，與支氣管炎同屬革蘭氏陰性菌可能涉入的感染，抗菌機制具共通性。不過，吸入給藥有引發支氣管收縮與氣道高反應性的記載，這是此預測最大的疑慮。

另外，文獻中有數篇研究是用 Polymyxin B 在動物身上誘發嗜酸性球性支氣管炎，或用於氣道激發試驗，這些並非治療證據，不應視為支持療效。

## 安全性考量

- **藥物交互作用**：已查得 73 筆交互作用，其中多項為重大（Major）等級，主要例子如下：
  - Amikacin（重大）
  - Cidofovir（重大）
  - Cisatracurium（重大）
  - Deferasirox（重大）
  - Botulinum toxin type A（重大）
  - Iothalamic acid、Diatrizoate（重大）
  - Capreomycin、Ethinylestradiol、Estradiol（中度）
- **吸入使用風險**：文獻指出吸入 Polymyxin B 可能引發支氣管收縮與氣道高反應性。
- **過敏反應**：有 Polymyxin B 併用 trimethoprim 眼藥水引起過敏性休克的個案報告。

其餘警語與禁忌症，請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 支氣管炎方面沒有任何臨床試驗，文獻僅有病例系列、生理研究與動物模型，多數屬於氣道激發或疾病模型用途，並非療效證據。
- 吸入給藥有支氣管收縮的安全疑慮，且台灣現有製劑皆為眼、耳、皮膚局部或原料粉劑，並無適合吸入的劑型。

**若要推進需要：**
- 釐清目標族群（例如多重抗藥革蘭氏陰性菌所致的氣管支氣管炎，而非一般支氣管炎）
- 評估吸入劑型與給藥途徑的可行性，並建立支氣管痙攣的預防與監測計畫
- 取得詳細的作用機轉資料
- 設計前瞻性對照試驗，驗證療效與安全性
- 針對重大藥物交互作用（尤其是腎毒性、神經肌肉阻斷相關藥物）制定用藥管理方案

**補充說明：**資料顯示該藥的結膜炎預測（TxGNN 分數 99.06%）有多項隨機對照試驗（多為 Polymyxin B／trimethoprim 複方對照 moxifloxacin 或 chloramphenicol）支持，證據等級為 L1，但與台灣已核准的眼科適應症重疊，屬既有適應症而非真正的新適應症。
