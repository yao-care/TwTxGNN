# Doripenem：從複雜性泌尿道與腹腔內感染到肝門靜脈硬化症

## 一句話總結

Doripenem 是一種碳青黴烯（carbapenem）類注射抗生素，原本用於治療複雜性泌尿道感染（包括腎盂腎炎）及複雜性腹腔內感染。
TxGNN 模型預測它可能對**肝門靜脈硬化症 (Hepatoportal Sclerosis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Doripenem 是碳青黴烯類抗生素，
一般認為其作用是抑制細菌細胞壁合成（結合青黴素結合蛋白），
對多種革蘭氏陰性與陽性菌具抗菌活性。

肝門靜脈硬化症的病理主要涉及門靜脈血管與纖維化變化，與細菌感染並無直接關聯。
目前沒有已知機轉能把 Doripenem 的抗菌作用連結到這類血管或纖維化病變，
因此這項預測在機轉上缺乏合理依據，僅能視為模型運算產生的訊號。

此外，TxGNN 對另外四個肝臟與門脈相關疾病（肝肺症候群、特發性銅相關肝硬化、早發性家族性非肝硬化門脈高壓、原發性門靜脈血栓）給出了完全相同的分數（99.00%），
顯示該分數在這些疾病之間缺乏區辨力，應謹慎解讀。

## 結論與下一步

**決策：Hold**

**理由：**
- 這項預測只有模型分數，沒有臨床試驗、文獻或機轉依據，證據等級為 L5。
- Doripenem 的抗菌機轉與肝門靜脈硬化症的病理缺乏已知關聯，且同批預測分數完全相同，可信度有限。

**若要推進需要：**
- 補充 Doripenem 的作用機轉資料，並釐清是否有合理的機轉連結（例如腸道細菌移位的間接影響）
- 進行文獻與臨床試驗的系統性檢索，確認是否有任何支持證據
- 若有前臨床或觀察性研究的訊號，再重新評估；同時需評估腎功能不全等風險族群的安全性
