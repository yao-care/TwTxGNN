# Methylprednisone：從風濕性關節炎與腎上腺皮質機能不全到痲瘋病（Leprosy）

## 一句話總結

Methylprednisone 是一種糖皮質素（類固醇），原本用於腎上腺皮質機能不全、休克、支氣管性氣喘、膠原疾病與過敏反應等。
TxGNN 模型預測它可能對**痲瘋病 (Leprosy)** 有效，但目前**沒有任何臨床試驗或文獻**支持，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Methylprednisone 屬於糖皮質素類藥物，具有抑制發炎與免疫反應的作用。

痲瘋病治療過程中常出現免疫性反應（如逆轉反應、結節性紅斑 ENL），糖皮質素在臨床上可用來控制這類發炎。因此機轉上有間接的關聯。但這屬於處理併發的免疫反應，並非針對痲瘋桿菌本身，且本次整理的資料中沒有任何直接證據，TxGNN 分數是唯一的支持。

## 安全性考量

安全性資訊請參考原廠仿單。

另外值得提醒：糖皮質素屬免疫抑制劑，用於感染性疾病時可能影響宿主防禦，使用前需審慎評估。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅有模型分數支持，沒有任何臨床試驗或文獻，證據等級為 L5。
- 糖皮質素在痲瘋病中的角色可能限於控制免疫性反應，而非治療疾病本身，需先釐清臨床定位。

**若要推進需要：**
- 補充詳細的作用機轉（MOA）資料
- 系統性搜尋糖皮質素用於痲瘋病反應（逆轉反應、ENL）的既有臨床文獻與指引
- 釐清預測目標是「治療感染」還是「處理免疫性併發症」
- 確認給藥途徑與劑型的相容性
- 建立感染風險與免疫抑制相關的安全性監測計畫
