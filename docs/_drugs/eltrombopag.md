# Eltrombopag：從免疫性血小板減少症到 HIV 感染相關疾病

## 一句話總結

Eltrombopag 是一種口服血小板生成素受體促效劑，原本用於治療對其他治療失敗的免疫性血小板減少症（ITP）、C 型肝炎相關血小板減少症及嚴重再生不良性貧血。
TxGNN 模型預測它可能對 **HIV 感染相關疾病 (HIV infectious disease)** 有效，但從現有資料來看，更合理的解讀是改善 HIV 相關的血小板減少，而非抗病毒作用。
目前有 **1 個臨床試驗**（相關性僅為間接）和 **8 篇文獻**，其中多為個案系列與回顧。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，eltrombopag 是血小板生成素受體促效劑，能刺激巨核細胞分化與血小板生成，在 ITP、C 型肝炎相關血小板減少及再生不良性貧血中的療效已被證實。

HIV 感染常合併血小板減少（包括 HIV 相關 ITP）。因此，TxGNN 的高分預測較可能反映的是**血小板數量層面的症狀性益處**，而不是對 HIV 病毒本身的抗病毒活性。文獻中的病例報告也支持這個方向：有難治型 HIV 相關 ITP 使用血小板生成素受體促效劑的病例系列，以及 HIV 相關再生不良性貧血使用 eltrombopag 後三系血球恢復的個案。其中一例還觀察到免疫調節現象（Th1、Th17 細胞下降，調節性 T 細胞比例上升），但僅為單一個案，不足以作為結論。

另有一項體外研究（2020 年）從 FDA 核准藥物庫中篩選 HIV-1 前病毒轉錄的調節劑，屬於早期探索性證據，與臨床療效仍有很大距離。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前沒有針對 HIV 族群的已完成對照試驗，現有證據僅為回顧、個案系列與一項體外研究，唯一的 Phase 3 試驗不是 HIV 族群且已提前終止。
- TxGNN 高分預測較可能反映「HIV 相關血小板減少」的症狀性益處，而非抗病毒作用，因此新適應症的定義需要先釐清。

**若要推進需要：**
- 將預測適應症重新定義為「HIV 相關血小板減少症 / HIV 相關 ITP」，而非 HIV 感染本身。
- 收集或進行針對 HIV 相關血小板減少族群的前瞻性研究（如 Phase 2 試驗），並系統性整理現有病例資料。
- 補齊作用機轉資料（MOA）。
- 評估肝功能風險（知識圖譜標示肝臟相關疾病為潛在禁忌）以及與抗反轉錄病毒藥物的交互作用。
- 確認台灣現行核准適應症不含 HIV 相關血小板減少，若推進屬於仿單外使用，需另行評估法規路徑。
