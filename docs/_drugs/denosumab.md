## Denosumab：從骨髓瘤及實質腫瘤骨轉移到嚴重非增殖性糖尿病視網膜病變
{: .text-alpha }

## 一句話總結

Denosumab 是 RANKL 抑制性單株抗體，原本用於預防多發性骨髓瘤及實質腫瘤骨轉移患者的骨骼相關事件，另有骨質疏鬆症等適應症。
TxGNN 模型預測它可能對**嚴重非增殖性糖尿病視網膜病變 (Severe Nonproliferative Diabetic Retinopathy)** 有效。
目前**沒有相關臨床試驗與文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。就已知資訊，Denosumab 是一種 RANKL 中和性單株抗體，可抑制破骨細胞的活性，因此用於骨轉移、骨巨細胞瘤、惡性高血鈣症與骨質疏鬆症等骨骼相關疾病。

原適應症（骨骼疾病）與糖尿病視網膜病變（視網膜微血管病變）在病理上差異很大。視網膜病變主要與 VEGF 驅動的血管新生和發炎有關，目前沒有已確立的機轉連結。因此，這項預測僅建立在 TxGNN 模型的計算結果上。

另一個值得注意的相鄰預測是**糖尿病視網膜病變 (Diabetic Retinopathy)**（TxGNN 分數 99.23%）。有假說認為 RANKL/RANK/OPG 訊號與血管鈣化及糖尿病併發症有關，但與視網膜病變的直接關聯尚未證實，只屬間接推論。

## 結論與下一步

**決策：Hold**

**理由：**
- 嚴重非增殖性糖尿病視網膜病變的預測僅來自模型，沒有任何臨床試驗或直接文獻，證據等級為 L5。
- 機轉上，RANKL 抑制與視網膜微血管病變之間缺乏已確立的連結。

**若要推進需要：**
- 補充詳細的作用機轉資料，並釐清 RANKL/RANK/OPG 訊號與視網膜病變的關聯。
- 進行前臨床研究（如糖尿病視網膜病變動物模型），驗證是否有保護效果。
- 針對現有世代資料，進行以視網膜病變為終點的回溯性分析。
- 評估給藥途徑（目前為皮下注射）與眼部疾病的可行性，以及糖尿病族群的安全性。
