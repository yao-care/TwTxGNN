# Inclisiran：從原發性高血脂症到鉀缺乏症（預測證據薄弱）

## 一句話總結

Inclisiran（樂脂益）是一種作用於肝臟的 siRNA 藥物，原本用於原發性高血脂症，以降低成人病人的低密度脂蛋白膽固醇（LDL-C）。
TxGNN 模型預測它可能對**鉀缺乏症 (Potassium Deficiency Disease)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Inclisiran 是一種小干擾 RNA（siRNA），在肝細胞中抑制 PCSK9 mRNA，藉此降低 LDL-C。

這個作用路徑與鉀的體內平衡沒有已知的關聯。原適應症（高血脂）屬於脂質代謝問題，鉀缺乏症則屬於電解質失衡，兩者在病理機轉上沒有明確的交集。

因此，TxGNN 給出的高分（99.93%）較可能反映知識圖譜中的間接關聯，而非實際的生物學或臨床證據。目前不能認為這個預測有機轉上的支持。

另外，在 TxGNN 的其他預測中（如食道疾病、偏頭痛、雷諾氏病等），同樣沒有找到有力的機轉或臨床證據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測的新適應症（鉀缺乏症）沒有任何臨床試驗或文獻支持，機轉上也缺乏合理連結，證據等級僅為 L5。
- 雖然模型分數很高，但這不足以支持推進再利用開發。

**若要推進需要：**
- 補充 Inclisiran 完整的作用機轉資料，並釐清是否存在與鉀代謝相關的任何生物學路徑
- 進行文獻回顧與前臨床研究，確認是否有支持此預測的訊號
- 補齊安全性資料（警語、禁忌症、藥物交互作用），再評估是否值得啟動臨床研究
- 若仍想探索新適應症，可考慮優先檢視與原適應症較相關的方向（例如兒童家族性高膽固醇血症，目前已有 Phase 3 試驗進行中），而非本預測
