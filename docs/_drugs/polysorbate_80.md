# Polysorbate 80：從界面活性劑（賦形劑）到先天性魚鱗癬樣紅皮症

## 一句話總結

Polysorbate 80 是一種非離子性界面活性劑，常作為乳化劑與賦形劑，用於疫苗、凝血因子製劑與眼用製劑等產品。
TxGNN 模型預測它可能對**先天性魚鱗癬樣紅皮症 (Congenital Ichthyosiform Erythroderma)** 有效，
但目前**沒有臨床試驗與文獻**支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。Polysorbate 80 是非離子性界面活性劑，主要作為賦形劑與乳化劑，並非以治療疾病為目的的活性成分。

先天性魚鱗癬樣紅皮症是一種以皮膚鱗屑與紅斑為特徵的遺傳性皮膚病。理論上，界面活性劑或乳化成分可能具有潤膚或調節皮膚屏障的作用，但這只是推測，沒有任何研究證據支持。

這個預測目前僅依據 TxGNN 的高分預測（0.994），沒有臨床試驗或文獻佐證。也需注意，它在台灣的相關產品多為複方，其療效來自其他活性成分，不能視為 Polysorbate 80 本身的療效。

## 結論與下一步

**決策：Hold**

**理由：**
- 證據等級為 L5，僅有模型預測，沒有臨床試驗或文獻支持。
- Polysorbate 80 主要作為賦形劑使用，缺乏作為活性成分的作用機轉資料，也沒有單方的有效許可證。

**若要推進需要：**
- 補充作用機轉資料，釐清 Polysorbate 80 對皮膚屏障或魚鱗癬病理的可能作用
- 進行文獻與臨床試驗檢索，確認是否存在任何相關研究
- 進行前臨床研究（如皮膚模型或動物模型），評估其作為外用活性成分的可行性
- 評估給藥途徑的相容性（目前尚未確認外用劑型）
- 補充安全性資料，包括賦形劑相關的過敏與刺激反應
