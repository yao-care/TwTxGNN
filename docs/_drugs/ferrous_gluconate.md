# 葡萄糖酸亞鐵（Ferrous gluconate）：從缺鐵性貧血到 Plummer-Vinson 症候群

## 一句話總結

葡萄糖酸亞鐵是一種補鐵劑，原本用於治療各種缺鐵性貧血。
TxGNN 模型預測它可能對 **Plummer-Vinson 症候群 (Plummer-Vinson syndrome)** 有效，
但目前針對此疾病**沒有臨床試驗和文獻**支持，證據僅來自模型預測與機轉推論。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，葡萄糖酸亞鐵是口服鐵劑，用來補充體內不足的鐵，在缺鐵性貧血中的角色已相當明確。

Plummer-Vinson 症候群的特徵是缺鐵性貧血合併食道蹼（esophageal web）與吞嚥困難。補鐵可矯正其根本的缺鐵問題，在臨床上本就是此病的標準處置之一，因此模型預測在機轉上合理。

不過要注意，這個預測其實更像是原適應症（缺鐵性貧血）的延伸，而不是全新的療效發現。此外，目前沒有任何針對此疾病的試驗或文獻資料可佐證，補鐵能否改善食道蹼本身的結構性問題，也缺乏資料。

## 安全性考量

- **模型提示的潛在禁忌（來自知識圖譜，非仿單內容）**：消化性潰瘍、遺傳性血色素沈著症、含鐵血黃素沉著症、鐵代謝疾病、威爾森氏症、潰瘍性結腸炎、發炎性腸道疾病、溶血性貧血、腸胃炎。
- **藥物交互作用**：共查得 80 筆，主要為中度交互作用，例如：
  - 氫離子幫浦抑制劑（rabeprazole、omeprazole、lansoprazole、pantoprazole、esomeprazole、dexlansoprazole）
  - 四環素類抗生素（doxycycline、tetracycline、minocycline）
  - 氟喹諾酮類（levofloxacin）
  - 制酸劑與礦物質（氧化鎂、碳酸鈣、氫氧化鋁、magaldrate）
  - 其他：pancrelipase、硫酸鈉、triethylenetetramine
  - 輕度交互作用：cimetidine、硫酸鋅、醋酸鋅

  多數屬於吸收干擾，臨床上通常需要錯開服藥時間。

其餘警語與禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 雖然 TxGNN 分數很高，也有合理的機轉連結，但針對 Plummer-Vinson 症候群沒有任何臨床試驗或文獻，且補鐵本來就是此病的既有處置，不構成新的再利用價值。
- 排名較後的預測（如巨母紅血球性貧血、食道畸形、生物素代謝疾病）機轉上關聯薄弱，不建議投入資源。

**若要推進需要：**
- 補齊作用機轉（MOA）資料
- 系統性檢索 Plummer-Vinson 症候群補鐵治療的文獻與登記試驗
- 評估補鐵對食道蹼與吞嚥困難症狀的實際效果
- 確認劑型與給藥途徑的適用性
- 針對潛在禁忌族群（消化性潰瘍、發炎性腸道疾病、鐵過載相關疾病等）及藥物交互作用，制定安全監測計畫
