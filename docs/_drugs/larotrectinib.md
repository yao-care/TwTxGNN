## Larotrectinib：從 NTRK 基因融合實體腫瘤到多發性內分泌腫瘤
{: .text-alpha }

## 一句話總結

Larotrectinib 是選擇性 TRK（NTRK1/2/3）抑制劑，在台灣核准用於具 NTRK 基因融合的實體腫瘤成人與兒童病人。
TxGNN 模型預測它可能對**多發性內分泌腫瘤 (Multiple Endocrine Neoplasia, MEN)** 有效，
但目前僅有 **1 個泛腫瘤籃式臨床試驗**（與本適應症間接相關）和 **2 篇文獻**（皆為間接證據），屬於研究假說階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Larotrectinib 是選擇性 TRK 抑制劑，在 NTRK 融合陽性實體腫瘤中的療效已被確立。

多發性內分泌腫瘤主要由 RET 或 MEN1 基因異常驅動，與 TRK 訊號路徑並無直接關聯。因此，若 Larotrectinib 有任何益處，也屬間接性：例如用於罕見的 NTRK 融合陽性內分泌腫瘤，或作為 RET 抑制劑治療後的旁路路徑標靶。

提供的文獻中，一篇為晚期甲狀腺癌標靶治療的回顧，另一篇為 RET 抑制劑抗藥性機制的體外研究。兩者皆未直接測試 Larotrectinib 對多發性內分泌腫瘤的效果。這個預測目前較適合視為待驗證的研究問題。

## 結論與下一步

**決策：Hold**

**理由：**
- TxGNN 分數雖高（0.9924），但 Larotrectinib 作用於 TRK，而多發性內分泌腫瘤主要由 RET 或 MEN1 異常驅動，缺乏直接機轉連結。現有試驗為泛腫瘤籃式試驗，文獻也沒有針對 MEN 的 Larotrectinib 臨床資料，證據僅達 L4。
- Larotrectinib 已在台灣上市，但核准範圍僅限 NTRK 融合陽性實體腫瘤，本預測並不在範圍內。

**若要推進需要：**
- 確認 MEN 相關腫瘤（如甲狀腺髓質癌、胰臟神經內分泌腫瘤）中 NTRK 融合的實際發生率
- 評估 NTRK 融合陽性的內分泌腫瘤個案，是否已可透過現有適應症（NTRK 融合實體腫瘤）使用
- 補充詳細的作用機轉（MOA）資料
- 蒐集 Larotrectinib 用於 RET 抑制劑抗藥後旁路活化病人的臨床或轉譯研究證據
- 查閱原廠仿單，補齊警語與禁忌症資訊
