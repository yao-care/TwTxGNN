## Anthralin：局部刺激性角質調節劑 → 光化性唇炎 (actinic cheilitis)
{: .text-alpha }

## 一句話總結

Anthralin 是一種外用的皮膚科藥物，具有抗增生與角質溶解作用。
TxGNN 模型預測它可能對**光化性唇炎 (actinic cheilitis)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個預測，僅屬模型推論階段。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Anthralin 在增生性皮膚疾病中具有抗增生與角質溶解活性，理論上可能作用於光化性唇炎中發生異常增生（dysplasia）的唇部上皮。

不過，這個推論目前僅來自模型預測，沒有臨床或文獻證據支持。此外，唇部屬黏膜與皮膚交界處，Anthralin 本身具有刺激性，用於唇部黏膜可能引起明顯刺激，是此方向的主要疑慮。

## 安全性考量

安全性資訊請參考原廠仿單。

另外需注意，Anthralin 為刺激性藥物，用於唇部或黏膜時可能加重局部刺激，這點在任何探索性研究中都應納入考量。

## 結論與下一步

**決策：Hold**

**理由：**
- 此預測僅來自 TxGNN 模型，沒有任何臨床試驗或文獻直接研究 Anthralin 用於光化性唇炎，證據等級為 L5。
- 藥物的刺激性與唇部黏膜的使用部位不相容，風險大於已知的潛在效益。

**若要推進需要：**
- 補齊 Anthralin 的作用機轉資料
- 搜尋並評估 Anthralin 或類似角質調節劑用於光化性唇炎的文獻與病例報告
- 評估唇部黏膜的耐受性與適當劑型、濃度
- 若有初步安全性與療效訊號，再考慮設計小規模探索性研究
