# Desogestrel：從避孕到閉經

## 一句話總結

Desogestrel 是一種黃體素（progestin），原本用於避孕，目前在台灣皆以複方形式上市。
TxGNN 模型預測它可能對**閉經 (Amenorrhea)** 有效，
目前有 **1 個臨床試驗**和 **10 篇文獻**與此方向相關，但多為間接證據。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Desogestrel 是活性代謝物 etonogestrel 的前驅藥，屬於黃體素類，常與乙炔雌二醇組成口服避孕複方，其避孕療效已被證實。

閉經（尤其是下視丘性或運動相關的低雌激素閉經）常伴隨骨密度流失。含黃體素的荷爾蒙療法可提供週期性的荷爾蒙補充，並可能有助保護骨密度，因此在機轉上有推論空間。不過這個連結是從藥物類別藥理推論而來，並非直接證據。

需要注意的是，現有資料中尚未看到以 Desogestrel 本身治療閉經的直接研究。相關文獻多半是避孕藥的一般性回顧，或將閉經視為黃體素單方避孕藥的出血型態之一（也就是副作用），而非治療目標。

## 安全性考量

- **禁忌症（知識圖譜推論，非仿單內容）**：知識圖譜中與本藥相關的禁忌疾病包括高血壓、癲癇、肝病、膽囊疾病、糖尿病、高三酸甘油脂血症、紅斑性狼瘡、氣喘、血栓性靜脈炎、乳癌及子宮肌瘤等；實際禁忌請以原廠仿單為準。
- **藥物交互作用**：共查得 43 筆，以下為資料中列出的中度交互作用，主要涉及降血糖藥物，可能影響血糖控制：
  - 胰島素類（insulin aspart、degludec、detemir、glulisine 等）
  - Metformin、Nateglinide、Rosiglitazone
  - GLP-1 類（Liraglutide、Lixisenatide、Albiglutide）
  - DPP-4 抑制劑（Alogliptin、Linagliptin）
  - SGLT2 抑制劑（Dapagliflozin、Ertugliflozin）
  - 其他：Aprepitant、Glycerol phenylbutyrate、Metreleptin

主要警語與仿單禁忌請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
- 閉經的預測分數很高，但現有證據都是間接的：唯一的臨床試驗並未指定 Desogestrel 為介入藥物，文獻也多為避孕藥的一般性回顧或觀察性研究，缺乏 Desogestrel 治療閉經的直接證據。
- 作用機轉資料缺漏，目前的機轉連結僅是依藥物類別推論。
- 在台灣，Desogestrel 目前皆以複方許可證上市，且閉經的病因多樣，需先釐清族群與用法。

**若要推進需要：**
- 補齊 Desogestrel 的作用機轉資料（MOA）
- 針對特定閉經類型（如下視丘性或運動相關閉經）設計或搜尋以 Desogestrel 為介入的對照研究，並評估骨密度等終點
- 確認黃體素單方與複方用於閉經的適用性，並釐清閉經作為單方避孕藥出血型態的區別
- 評估禁忌疾病與降血糖藥物交互作用等安全性風險，建立納入與排除條件
- 若有意探討其他預測適應症，痤瘡（acne）已有 Phase 4 試驗與多篇文獻，證據等級為 L2，可優先納入評估
