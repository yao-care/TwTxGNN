# Glycerin（甘油）：從便秘到顱底馬尾症候群（Cauda Equina Syndrome）

## 一句話總結

甘油（Glycerin）是常見的滲透性通便成分，原本用於緩解便秘（浣腸劑）。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有臨床試驗、也沒有相關文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，甘油是滲透性通便劑與保濕劑，浣腸使用時藉由吸水、潤滑腸道而促進排便。

馬尾症候群是脊椎神經根受壓迫所造成的神經外科急症，通常需要緊急手術減壓。從藥理上看，甘油的滲透與保濕作用與這類壓迫性神經疾病沒有明確關聯，因此這項預測缺乏機轉依據，應視為模型的統計關聯而非可信的治療假說。

TxGNN 分數雖高（99.60%），但在排名中僅位於第 9055 名，且沒有任何實證佐證，不宜據此推進。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有臨床試驗與文獻支持，且機轉上找不到甘油與馬尾症候群（需手術處理的壓迫性神經急症）之間的合理連結。

**若要推進需要：**
- 補充甘油的作用機轉資料，並提出可檢驗的機轉假說
- 系統性檢索是否有任何臨床或前臨床研究支持此適應症
- 在缺乏上述證據前，不建議投入進一步開發資源

**補充觀察：**同一份預測清單中，開放角度青光眼（open-angle glaucoma）有 3 篇間接文獻（證據等級 L4），口服或靜脈甘油確實可短暫降低眼壓，但文獻內容並未直接評估甘油治療此疾病，且長期使用缺乏支持，目前同樣建議 Hold。
