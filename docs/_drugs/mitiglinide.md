# Mitiglinide：從第二型糖尿病到 Opsismodysplasia

## 一句話總結

Mitiglinide 是短效型促胰島素分泌劑，原本用於改善第二型糖尿病患者的餐後血糖。
TxGNN 模型預測它可能對 **Opsismodysplasia（一種罕見骨骼發育不良）** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料（原廠 MOA 資料欠缺）。依一般藥理知識，Mitiglinide 是短效型促胰島素分泌劑，作用於胰臟 β 細胞的 K-ATP 通道（Kir6.2/SUR1），使通道關閉而促進胰島素分泌。

Opsismodysplasia 是一種罕見的骨骼發育不良，由 INPPL1（SHIP2）功能喪失所致，而 SHIP2 與 PI3K／胰島素訊號路徑有關。因此兩者在「胰島素訊號」層面有間接的連結想像空間。

然而，K-ATP 通道阻斷與 INPPL1 路徑之間**並沒有已確立的直接機轉關聯**。0.99 的預測分數目前沒有任何臨床或文獻證據佐證，應視為待驗證的假說，而非有力的再利用依據。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型，沒有臨床試驗、文獻或明確的機轉證據支持（證據等級 L5）。
- 藥物的 K-ATP 通道作用與 Opsismodysplasia 的致病機轉（INPPL1 功能喪失）之間缺乏直接關聯。此外，Opsismodysplasia 為罕見的骨骼發育疾病，與成人糖尿病用藥的使用情境差異很大。

**若要推進需要：**
- 補齊完整的作用機轉（MOA）資料，並進行機轉層面的連結分析
- 以前臨床研究（如 INPPL1 缺失的細胞或動物模型）檢驗 Mitiglinide 是否有任何作用
- 系統性檢索文獻與臨床試驗登記，確認是否有相關的先行研究
- 評估目標族群（多為兒童）使用此藥的可行性與安全性，並補充安全性資料（警語、禁忌、藥物交互作用）
