# Sennosides：從便秘到頭皮毛髮稀疏症

## 一句話總結

Sennosides（番瀉苷）是刺激性瀉藥，原本用於緩解便秘。
TxGNN 模型預測它可能對**頭皮單純性毛髮稀疏症 (Hypotrichosis Simplex of the Scalp)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Sennosides 是刺激性緩瀉劑，其活性代謝物 rheinanthrone 作用於結腸黏膜，增加腸道蠕動與分泌，因而緩解便秘。

在機轉上，這個作用與毛囊生長之間**沒有已知的合理連結**。Sennosides 主要在結腸局部作用，全身吸收極少，也沒有文獻記載它具有促進毛髮生長或調節毛囊的活性。因此，高分預測目前僅是圖譜運算的結果，屬於推測性質，不能視為機轉上的支持。

同一次預測中，其他排名靠前的候選適應症還包括先天性毛髮稀疏併粟粒疹、瀰漫性圓禿、開角型青光眼、原發性遺傳性青光眼與一般禿髮。這些適應症同樣沒有臨床或文獻證據，也沒有可辨識的作用機轉連結，顯示模型預測可能反映的是圖譜結構上的關聯，而非真實的藥理作用。

## 結論與下一步

**決策：Hold**

**理由：**
- 目前只有 TxGNN 的模型預測（證據等級 L5），沒有任何臨床試驗或文獻佐證。
- 藥物作用於結腸局部、全身吸收極少，與毛髮生長沒有已知的機轉連結，預測的生物學合理性很低。

**若要推進需要：**
- 補充詳細的作用機轉資料（MOA），評估是否存在任何可能影響毛囊的途徑
- 進行文獻與臨床試驗登記的系統性檢索，確認是否有任何相關研究
- 若仍想探索，需先進行前臨床（細胞或動物毛囊模型）研究
- 評估給藥途徑的相容性：目前台灣上市劑型均為口服或粉劑，而毛髮相關適應症通常需要局部給藥，需重新評估劑型與全身暴露的可行性
