# Cladribine：從復發型多發性硬化症與毛髮狀細胞白血病到副腦膜胚胎型橫紋肌肉瘤

## 一句話總結

Cladribine 是一種嘌呤核苷類似物，在台灣核准用於復發型多發性硬化症與毛髮狀細胞白血病。
TxGNN 模型預測它可能對**副腦膜胚胎型橫紋肌肉瘤 (Parameningeal Embryonal Rhabdomyosarcoma)** 有效，
但目前**沒有任何臨床試驗或直接相關文獻**支持，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cladribine 是嘌呤核苷類似物，會被去氧胞苷激酶（deoxycytidine kinase）磷酸化，干擾 DNA 合成與修復，作用對象主要是淋巴球。這也是它能用於毛髮狀細胞白血病（血液腫瘤）與多發性硬化症（免疫介導疾病）的基礎。

橫紋肌肉瘤是源自間質組織的實體腫瘤，與淋巴球惡性疾病在細胞來源上差異很大。Cladribine 與此疾病的關聯目前僅來自 TxGNN 知識圖譜的預測，沒有臨床或文獻佐證，機轉上的合理性仍待驗證。

同一份預測清單中，排名前列的多為橫紋肌肉瘤的各種亞型（如陰道葡萄狀型、肝外膽管型、前列腺胚胎型等），分數介於 99.74% 至 99.77%，顯示模型對這一類疾病有一致的預測傾向，但這並不等同於實際療效證據。另有「肝肉瘤 (liver sarcoma)」一項，僅檢索到一篇討論冒煙型全身性肥大細胞增生症的病例報告（2004 年），與肝肉瘤無直接關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型（L5），沒有任何臨床試驗或直接相關文獻。
- Cladribine 的作用對象以淋巴球為主，與橫紋肌肉瘤這類間質來源實體腫瘤的機轉關聯尚未建立，且藥物本身有明顯的骨髓抑制與神經毒性風險。

**若要推進需要：**
- 補充詳細的作用機轉資料（MOA），釐清與橫紋肌肉瘤的生物學連結。
- 進行系統性文獻檢索，並尋找橫紋肌肉瘤細胞株或動物模型的前臨床證據。
- 評估該族群（多為兒童及青少年）的風險效益與給藥途徑可行性。
- 取得仿單完整的警語與禁忌資訊，確認血液學與神經毒性的風險管理方式。
