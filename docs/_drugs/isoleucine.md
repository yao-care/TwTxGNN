# Isoleucine：從營養補給到胃輕癱

## 一句話總結

Isoleucine（異白胺酸）是人體必需的支鏈胺基酸，原本用於營養補給與靜脈營養。
TxGNN 模型預測它可能對**胃輕癱 (Gastroparesis)** 有效，
但目前**沒有任何臨床試驗或文獻**支持這個方向，僅有模型預測分數。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Isoleucine 是必需胺基酸，用於營養補充與靜脈營養，其在營養支持上的角色已確立，但並無已知路徑將它與胃部蠕動或胃輕癱連結。

原適應症（營養補給、蛋白質缺乏的治療）與胃輕癱（胃排空延遲的動力障礙）在病理上關聯有限。雖然胃輕癱病人常有營養不良，需要營養支持，但那是「營養支持」而非「治療疾病本身」。

因此，這項預測目前僅來自模型的高分（0.993），尚未有臨床或文獻佐證，機轉合理性須由後續研究驗證。
