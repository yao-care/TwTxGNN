# Tazarotene：從乾癬到脂漏性皮膚炎

## 一句話總結

Tazarotene（他扎羅汀）是外用類視黃醇（retinoid），原本用於乾癬及尋常性痤瘡。
TxGNN 模型預測它可能對**脂漏性皮膚炎 (Seborrheic Dermatitis)** 有效，
但目前**沒有臨床試驗和文獻**直接支持，證據僅來自模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Tazarotene 是外用類視黃醇前驅藥，在體內轉換為活性形式 tazarotenic acid，可選擇性結合 RAR-beta/gamma 受體，調節角質細胞分化並減少過度增生與發炎。

乾癬與脂漏性皮膚炎都是以皮膚發炎、角質細胞異常增生與脫屑為特徵的慢性皮膚病。Tazarotene 在乾癬中的作用（使角質細胞分化正常化、減少過度增生）在機轉上可能也與脂漏性皮膚炎的脫屑和發炎相關。

不過，這個關聯目前僅建立在 TxGNN 預測與機轉推論上，並無臨床試驗或文獻驗證。

**其他預測適應症（供參考）：**
- **脂溢性角化症 (Seborrheic Keratosis)**，預測分數 99.51%：有 2 篇相關文獻（1 篇 2023 年外用治療系統性回顧、1 篇 2004 年比較冷凍治療與外用 calcipotriene、tazarotene、imiquimod 的研究），證據等級 L3。但僅憑現有摘要，無法確認其對 tazarotene 療效的具體結論。
- **外陰倒置性毛囊角化症 (Vulvar Inverted Follicular Keratosis)**，預測分數 99.38%：無任何臨床或文獻證據（L5），且外陰部位對類視黃醇的刺激耐受性較差。

## 安全性考量

- **知識圖譜標示的禁忌疾病**（來自 TxGNN 知識圖譜關聯，非仿單內容）：光反應性癲癇反應 (photoparoxysmal response)、光敏感性疾病 (photosensitivity disease)、曬傷 (sunburn)。
- **藥物交互作用**：資料庫共查得 25 筆，列出的項目包括 Doxycycline、Minocycline、Adapalene、Tretinoin、Clobetasol、Tacrolimus、Omeprazole、Diclofenac 等，但嚴重程度分級均為未知。其中同為類視黃醇的 Adapalene、Tretinoin，以及四環素類（Doxycycline、Minocycline），在臨床上合併使用時應特別留意。
- 此外，預測部位若為外陰，需考量類視黃醇的刺激性，且懷孕期間應避免使用。

其餘警語與禁忌症請參考原廠仿單。

## 結論與下一步

**決策：Hold**

**理由：**
脂漏性皮膚炎的預測僅有 TxGNN 模型分數（99.79%）與機轉推論支持，沒有任何臨床試驗或文獻，證據等級為 L5。Tazarotene 已在台灣廣泛上市，但現有核准適應症為乾癬及尋常性痤瘡，尚無依據推進新適應症。

**若要推進需要：**
- 取得詳細的作用機轉資料（MOA），釐清 RAR-beta/gamma 路徑與脂漏性皮膚炎病理的關聯
- 系統性檢索脂漏性皮膚炎相關的臨床前與臨床研究，確認是否有任何初步證據
- 若要考慮脂溢性角化症，需詳讀上述兩篇文獻全文，確認 tazarotene 的實際療效與與其他外用藥物（如冷凍治療）的比較結果
- 設計小規模探索性試驗，並評估局部刺激性與光敏感相關風險
- 補充原廠仿單的警語與禁忌症資料
