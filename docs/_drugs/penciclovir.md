# Penciclovir：從唇皰疹到肝吸蟲症（Fascioliasis）

## 一句話總結

Penciclovir 是一種鳥嘌呤核苷類似物抗病毒藥，原本用於治療由單純皰疹病毒引起的復發性唇皰疹。
TxGNN 模型預測它可能對**肝吸蟲症 (Fascioliasis)** 有效，但目前**沒有任何臨床試驗與文獻**支持，僅有模型預測，且機轉上缺乏合理連結。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Penciclovir 是鳥嘌呤核苷類似物，經皰疹病毒的胸苷激酶選擇性磷酸化後，抑制病毒 DNA 聚合酶，因而在唇皰疹中具有療效。

然而，肝吸蟲症是由吸蟲引起的寄生蟲感染，沒有病毒胸苷激酶這個活化標的，因此機轉上找不到合理的連結。這個預測目前只建立在 TxGNN 的模型分數上，應視為需要審慎看待的訊號，而非有依據的假說。

另外值得注意的是，同一份預測清單中的其他項目（如囊蟲症、腸道蠕蟲症、各型間皮瘤等）同樣缺乏機轉支持，顯示這類高分預測可能是模型的假象。

## 結論與下一步

**決策：Hold**

**理由：**
- 預測僅來自模型分數，沒有臨床試驗或文獻佐證（證據等級 L5）。
- Penciclovir 的活化依賴病毒胸苷激酶，吸蟲無此標的，且台灣上市劑型以外用乳膏為主，全身暴露有限，機轉與給藥途徑均不支持此新適應症。

**若要推進需要：**
- 補充詳細的藥物作用機轉資料（MOA）
- 進行體外抗寄生蟲活性試驗，確認是否有任何直接作用
- 釐清是否存在非病毒胸苷激酶依賴的潛在機轉
- 評估給藥途徑的可行性（外用乳膏無法有效作用於肝膽寄生蟲感染）
- 在上述基礎研究未提供正向證據前，不建議投入臨床開發資源
