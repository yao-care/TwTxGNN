# Urofollitropin：從不排卵不孕症到偏頭痛（模型預測）

## 一句話總結

Urofollitropin 是從尿液中純化的促性腺激素（具 FSH／LH 活性），原本用於治療不排卵不孕症與輔助生殖技術中的卵巢刺激。
TxGNN 模型預測它可能對**偏頭痛 (Migraine Disorder)** 有效，但目前**沒有任何臨床試驗或文獻**支持這個方向，僅屬模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Urofollitropin 是尿液來源的促性腺激素，作用於性腺的 FSH／LH 受體，用來促進濾泡發育與排卵。

目前沒有已建立的機轉能把這類藥物與偏頭痛連結起來。唯一較具推測性的關聯，是女性偏頭痛與雌激素濃度波動有關，促性腺激素可能間接影響性荷爾蒙，進而調節偏頭痛。但這只是推測，並無臨床或文獻資料支持。

因此，這個預測目前只能視為模型的初步訊號，合理性有限。模型也同時給出其他高分預測（如腦幹先兆偏頭痛、馬尾症候群、His 束心搏過速、不寧腿症候群等），多數與藥物機轉的關聯同樣薄弱，顯示高分可能反映知識圖譜的網絡特性，而非真實的藥理關聯。

## 結論與下一步

**決策：Hold**

**理由：**
- 偏頭痛的預測僅有模型分數，沒有臨床試驗、文獻或明確的作用機轉支持，證據等級為 L5。
- 此藥物的核准用途（誘導排卵）與偏頭痛的病理差異很大，且屬需專業監督的注射型生殖用藥，在缺乏證據下不宜推進。

**若要推進需要：**
- 補齊作用機轉資料，並評估性荷爾蒙波動與偏頭痛之間是否存在可驗證的機轉。
- 系統性檢索文獻與臨床試驗登記，確認是否有任何支持偏頭痛的初步研究。
- 若有初步訊號，先進行前臨床或小規模探索性研究，並評估注射給藥途徑與長期使用於非生殖族群的可行性及安全性。
- 其他排名較高的預測（如腦幹先兆偏頭痛）同樣缺乏證據，不建議優先處理。
