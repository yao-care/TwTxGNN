# Tyrosine：從酪胺酸補給與血液腫瘤適應症到 Cauda Equina Syndrome（馬尾症候群）

## 一句話總結

Tyrosine（酪胺酸）是人體的胺基酸，在台灣許可證中同時涵蓋胺基酸營養劑與數種酪胺酸激酶抑制劑（TKI）產品。
TxGNN 模型預測它可能對**馬尾症候群 (Cauda Equina Syndrome)** 有效，但目前**沒有臨床試驗**，也**沒有文獻**支持這個方向，僅有模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。酪胺酸是兒茶酚胺（多巴胺、正腎上腺素等）的前驅物，也是甲狀腺激素合成的原料，但沒有任何已知機轉能把它與馬尾症候群連結。

馬尾症候群是脊椎神經根受壓迫所造成的神經外科急症，治療核心是手術減壓，而非補充營養或藥物。因此這項預測目前只來自 TxGNN 的知識圖譜模型，缺少機轉上或臨床上的合理依據。

此外，資料中另有幾個排名較後的預測（如甲狀腺機能亢進、高甲狀腺素血症），機轉上反而可能對病情不利，因為酪胺酸是甲狀腺激素的結構基礎。
