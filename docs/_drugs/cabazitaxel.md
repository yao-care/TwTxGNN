# Cabazitaxel：從去勢抗性轉移性前列腺癌到女性乳癌

## 一句話總結

Cabazitaxel（卡巴紫杉醇）是一種紫杉烷類（taxane）細胞毒性藥物，原本與 prednisone 或 prednisolone 併用，治療已接受過 docetaxel 的去勢抗性轉移性前列腺癌。
TxGNN 模型預測它可能對**女性乳癌 (Female Breast Carcinoma)** 有效。
目前本報告所整理的資料中**沒有已登記的臨床試驗**，文獻共 **19 篇**，多為前臨床配方研究與綜述，另有 2 篇為 GENEVIEVE 第二期研究（新輔助治療）的報告。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。根據已知資訊，Cabazitaxel 屬於紫杉烷類微管穩定劑，透過穩定微管、阻斷有絲分裂來抑制腫瘤細胞增生。這與乳癌化療中常用的 paclitaxel、docetaxel 屬於同一類機轉。

前列腺癌與乳癌雖然器官不同，但同屬對激素與增生訊號敏感的實體瘤，且紫杉烷類在兩者中都有地位。文獻指出，cabazitaxel 受 P-glycoprotein 介導抗藥性的影響較小，對已對其他紫杉烷產生抗藥的細胞株仍有活性，這對復發或難治型乳癌具有探索價值。

現有支持證據大多是前臨床研究，例如脂質載體與奈米粒子配方在乳癌細胞株和異種移植模型中的表現，以及對三陰性乳癌免疫治療的影響。臨床方面，已有 cabazitaxel 與 capecitabine 併用於轉移性乳癌的 I/II 期研究，以及與 paclitaxel 比較的新輔助第二期研究。這些資料支持此方向值得進一步研究，但尚不足以支持臨床使用。

## 結論與下一步

**決策：Proceed with Guardrails**

**理由：**
- 機轉上與現有乳癌紫杉烷類化療一致，且已有 GENEVIEVE 第二期隨機研究和第一/二期併用研究，使此方向有臨床探索基礎。
- 但目前沒有已登記的臨床試驗，證據多為前臨床研究，毒性（尤其骨髓抑制）也較明顯，因此只適合在有安全防護的前提下推進研究，不建議直接用於臨床。

**若要推進需要：**
- 完整取得並審閱 GENEVIEVE 的療效與安全性結果，確認相對於 paclitaxel 的獲益與風險。
- 補充作用機轉資料（MOA）。
- 設計以特定乳癌亞型（如三陰性乳癌或紫杉烷抗藥族群）為對象的第二期以上試驗。
- 建立骨髓抑制與感染風險監測計畫，以及 CYP3A 交互作用管理。
- 評估目標族群的肝腎功能與血液學條件，並確認在台灣使用的法規途徑（仿單外使用或新增適應症）。

**其他預測適應症備註：** 排名第 2–10 的預測（鐮狀細胞相關血紅素病變、HIV、甲狀腺機能亢進、神經母細胞瘤、類風濕性關節炎）目前都只有模型預測，沒有臨床或文獻證據，且多數缺乏合理的機轉連結，建議維持 Hold。神經母細胞瘤在抗有絲分裂機轉上有可能性，但仍需前臨床資料支持。
