## 碳酸鈉 (Sodium carbonate)：鹼化劑 → 馬尾症候群 (cauda equina syndrome)
{: .text-alpha }

## 一句話總結

碳酸鈉是一種鹼化劑；以碳酸鈉為主成分的單方許可證（「展旺」無菌碳酸鈉，已註銷）用途為無菌製劑的鹼化輔助劑，現行有效許可證中碳酸鈉則是注射用抗生素的賦形劑及複方點眼液、胃散的成分。
TxGNN 模型預測它可能對**馬尾症候群 (cauda equina syndrome)** 有效，但目前**沒有任何臨床試驗或文獻**直接支持這個方向，僅為模型預測。

## 為什麼這個預測合理？

目前缺乏詳細的作用機轉資料。碳酸鈉屬於鹼化劑，主要作用是調整酸鹼值，或在無菌製劑中作為輔助劑。

馬尾症候群是脊髓下段神經根受壓迫所造成的神經病變，主要處置是手術減壓。碳酸鈉的藥理作用與神經壓迫、神經損傷或修復並無已知關聯，這項預測目前只來自 TxGNN 模型的分數，缺乏機轉上的支持。

因此，這個預測應視為待驗證的假設，而不是有依據的再利用方向。

## 結論與下一步

**決策：Hold**

**理由：**
- 沒有任何臨床試驗或文獻直接研究碳酸鈉用於馬尾症候群，證據等級為 L5。
- 藥理上找不到合理的作用連結，預測僅來自模型分數。

**若要推進需要：**
- 取得碳酸鈉的作用機轉資料，並評估其與神經根壓迫性病變的可能關聯
- 進行系統性文獻檢索，確認是否存在任何直接相關的前臨床或臨床研究
- 在有機轉依據之前，不建議投入臨床開發資源
